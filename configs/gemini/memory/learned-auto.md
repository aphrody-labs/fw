- [rule] **Zero false completion & zero premature pauses**: Never claim "done" or summarize partial work as complete; re-check every item in the user's request and verify each with executable proof (compile, clippy/lint, tests, live API/browser render — never bare HTTP 200). - [rule] **Exact-read-before-edit & overwrite safety (fixes 173 `edit_file` + 12 `write_file` errors)**: Always `read_file` the exact target lines immediately before calling `edit_file` (never reconstruct target text from memory); always pass `Overwrite: true` to `write_file` when replacing an existing file.
- [rule] **Windows PowerShell 5.1 & CLI hygiene (fixes 1,022 shell/quoting/jq errors)**: Chain commands with `;` (never `&&`), call `curl.exe` (never `curl` alias), pass multi-line scripts via `@' ... '@ | bun -` heredoc stdin (never `bun -e "..."` with nested quotes), parse JSON via Bun stdin or `| ConvertFrom-Json` (never `gh api --jq` with backslashes), and avoid `??` or `ls -lh`.
- [rule] **SQLite & Windows DLL lock safety (fixes 44 SQLite + 6 `os error 5` errors)**: Finalize all `bun:sqlite` prepared statements before `db.close()`; shadow-copy native `.dll` files to `%TEMP%` before `bun:ffi` `dlopen`; pin `[test] root = "./tests"` in `bunfig.toml`.
- [rule] **Fleet offload & `/srv/` discipline**: Offload heavy Rust/C++ builds to `fr1`/`fr2` under `/srv/` only; never saturate the local workstation or create work directories under `/home/ubuntu`.
- [rule] **Bounded execution (fixes 38 hung commands)**: Always bound external HTTP/API requests with explicit timeouts (`AbortSignal.timeout`) and background heavy builds (`WaitMsBeforeAsync <= 1500`); parallelize independent tool calls (`fr1`, `fr2`, `gh`, `bun`, `browser`).
- [rule] **Windows Bun HTTP2/3 env guard**: Never set `BUN_FEATURE_FLAG_EXPERIMENTAL_HTTP2_CLIENT` or `BUN_FEATURE_FLAG_EXPERIMENTAL_HTTP3_CLIENT` in Windows User/Machine env (breaks Bun-compiled CLIs with `HTTP2StreamReset`; scope per-command only).
