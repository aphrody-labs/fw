# ADR-4: Aphrody OS on an LFS bootstrap, Nix packages, kernel.org + CachyOS

Status: accepted, 2026-11-16.

## Decision
- **Bootstrap**: the Linux From Scratch method (book 13.1 today) only for stage 0, chapters 5 to 7: cross
  toolchain, temporary tools, chroot. The stages are generated from the book's XML (lfs-book submodule) and built
  in a chroot on the build host.
- **Packages**: from that base, every package (LFS chapter 8 and BLFS) is a Nix derivation in `os/pkgs/`. The
  running OS has one package manager.
- **Kernel**: kernel.org at the newest release line, with the CachyOS patch set (`CachyOS/linux-cachyos`) for
  desktop scheduling; Rust for Linux where the kernel supports it.
- **Desktop**: BLFS Wayland stack and Mesa, with our shell (`apps/shell`, Rust on GPUI) providing the Googlebook
  features listed in `docs/features.toml`.
- **Android apps**: Waydroid (Android in a Linux container); Rust in AOSP through Soong `rust_*` modules when we
  build that side.
- **Installer**: a Rust program in `crates/ay_os_installer`, modeled on archinstall and the CachyOS CLI installer;
  A/B system slots with rollback.

## Later option
An AOSP-native desktop track, as `Mhsbrian/OpenBook` does (AOSP 17, GKI 6.18, Mesa), recorded but not the base.
