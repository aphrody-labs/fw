# ay-media Documentation

- [crates/ay-media-core](../../crates/ay-media-core/src/ay_media_core.rs): Rust + C + NASM x86_64 low-level pixel/luma kernels.
- [crates/ay-media-hls](../../crates/ay-media-hls/src/ay_media_hls.rs): Pure-Rust `#![forbid(unsafe_code)]` HLS M3U8 playlist parser.
- [submodules.toml](../../submodules.toml): the `aphrody-labs` forks of the media upstreams (FFmpeg, yt-dlp, hyperframe, hls.js, dav1d, rav1e, SVT-AV1) under `third_party/media/`.
