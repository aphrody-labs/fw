## Global options

These options work with every command.

| Option | Meaning |
|---|---|
| `-C, --directory <DIR>` | Change working directory before running [env: FW_WORKING_DIR] |
| `--config <FILE>` | Path to config file [env: FW_CONFIG] |
| `--offline` | Disable network access [env: FW_OFFLINE] |
| `--json` | Emit machine-readable JSON output |
| `--color <WHEN>` | Color output: auto, always, never |
| `-q, --quiet` | Reduce output verbosity |
| `-v, --verbose` | Increase output verbosity |
| `-c` | Resume latest interactive session (when no command given) |
