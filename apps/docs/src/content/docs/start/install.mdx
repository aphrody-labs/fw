Install the `fw` binary. It is one file. The latest `dev` build is `2026.11.21-fc4f4fa`, published 2026-11-21.

<Tabs syncKey="os">

```bash
curl -fsSL https://fw.aphrody.com/install.sh | sh
```

</TabItem>
<TabItem label="Windows">

```powershell
irm https://fw.aphrody.com/install.ps1 | iex
```

</TabItem>
</Tabs>

Check the install:

```bash
fw --version
```

## Update and remove

```bash
fw self-update --check
fw self-update
fw self-uninstall --purge-data
```

`fw self-update` verifies the SHA-256 of the download and keeps the previous binary as `.prev`. `--purge-data` also removes `~/.fx`.
