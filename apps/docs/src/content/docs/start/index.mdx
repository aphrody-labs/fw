Each step is one action. Do them in order.

## 1. Open a terminal

On Windows, open PowerShell. On Linux, open any terminal.

## 2. Install fw

Follow the [install page](/start/install/) for your system. It takes one command.

## 3. Check the version

Run this command.

```bash
fw --version
```

The output starts with `fw 2026.11.0` or a newer number.

## 4. Check your machine

```bash
fw doctor
```

The command checks the toolchain, `FX_HOME`, git, API keys and Ollama on port 11434. Fix what it reports, then run it again.

## 5. Go to your project

```bash
cd path/to/your/project
```

## 6. Describe the project to agents

```bash
fw onboard
```

The usage is `fw onboard [dir] | fw onboard export <all|mcp|opencode|zed> [--dir <dir>]`. The command describes the workspace for agents.

## 7. Write the agent config files

```bash
fw onboard export all
```

This writes `.mcp.json`, `opencode.json` and `.zed/settings.json` in the project. Open one and check that it lists the fw MCP server.

## 8. Ask the agent a question

```bash
fw ask "what does this project do?"
```

The agent needs a model endpoint. Run `fw models` to see the configured providers.

## 9. Start the server

```bash
fw serve 127.0.0.1:8787
```

The usage is `fw serve [host:port]`. Open `http://127.0.0.1:8787/` in your browser to see the chat page. The server also answers on `/mcp`, `/acp` and `/a2a`: see the [API reference](/api/fw-serve/).
