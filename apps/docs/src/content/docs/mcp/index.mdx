The fw MCP server exposes 17 tools over JSON-RPC 2.0 on stdio. Start it from a fw checkout with `bun src/fw_cli.ts mcp`, or use `fw serve` and post to `/mcp`.

## Tools

| Tool | What it does |
|---|---|
| [`crates_awesome`](/mcp/crates-awesome/) | The ranked best crates of a crates.io category, or the index of every awesome list when no category is given. |
| [`crates_compare`](/mcp/crates-compare/) | Compare two or more crates side by side with the best crate per metric. |
| [`crates_info`](/mcp/crates-info/) | One crate: score with its components, downloads, dependents, releases, MSRV, licence, advisories, rank overall and per category; live=true adds the live sparse-index record. |
| [`crates_search`](/mcp/crates-search/) | Search the ranked crates.io dataset by words (name, keywords, categories, description); results ordered by relevance then score. |
| [`crates_stack`](/mcp/crates-stack/) | Pick crates from the ranking for a goal in words (for example `web API with Postgres and auth`) and return the choices with reasons and a Cargo project skeleton. |
| [`fw_ai`](/mcp/fw-ai/) | Query Fw AI Brain (FTS5), Soul constitution, Router providers, or Low-Level LTO/AOT matrix. |
| [`fw_ast_parse`](/mcp/fw-ast-parse/) | Parse a source file using Fw's Fat-LTO Rust Tree-sitter C ABI across 12 grammars (rust, typescript, tsx, javascript, python, c, cpp, java, kotlin, go, json, bash). |
| [`fw_bridge`](/mcp/fw-bridge/) | Inspect or dispatch to Fw's absorbed first/third-party subsystems (heretic, neon/REA, craft-libs, craft-anything, ghidra). |
| [`fw_disasm`](/mcp/fw-disasm/) | Disassemble PE entry-point x86-64 instructions using craft-pe + iced-x86 Fat-LTO ABI, or identify any file via craft-sniff. |
| [`fw_learn`](/mcp/fw-learn/) | Run `fw learn` (status, harvest, distill, search, loop). |
| [`fw_pe_inspect`](/mcp/fw-pe-inspect/) | Inspect a Windows PE/COFF binary using craft-pe compiled into Fw's Fat-LTO ABI. |
| [`fw_status`](/mcp/fw-status/) | Return Fw monorepo status, Rust C ABI (v4) health, absorbed modules and plugin status. |
| [`fw_target_scan`](/mcp/fw-target-scan/) | Scan all registered in-repo Fw modules (heretic, neon, craft-libs, craft-anything, native/*, src, tests), run AST probes, and update target/manifest.json. |
| [`fw_tui_terminal`](/mcp/fw-tui-terminal/) | Inspect and run Fw-optimized Microsoft Intelligent Terminal (WTA) and tui-test source-only workflows. |
| [`fw_vfs`](/mcp/fw-vfs/) | Interact with Fw SQLite CAS VFS OS (mounts, ls, read, write). |
| [`kernel_graph`](/mcp/kernel-graph/) | Query the tree-sitter code graph of a pinned Linux kernel tree (symbols, definitions, references, includes, call edges, Kconfig and Kbuild links) with file:line answers. Build it first with `fw kernel graph build` on a host that has the tree. |
| [`kernel_status`](/mcp/kernel-status/) | Linux kernel pins (mainline, stable, CachyOS and its PKGBUILDs from kernel.toml) against kernel.org releases.json (mainline, stable, longterm, linux-next) and the newest CachyOS tags: behind and inconsistent pins, gitlinks, remote tags. |

## Call a tool

Send `initialize`, then `tools/list`, then `tools/call` with the tool name and its arguments. Each tool page has a ready example.

## How this list is made

`fw site` starts the server, sends `tools/list` and reads the answer. A tool added to `src/mcp_server.ts` appears here on the next run.
