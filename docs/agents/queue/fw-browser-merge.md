# fw-browser-merge: browser into fw, headless WebAssembly and WebGPU engine

Merge `aphrody-labs/browser` into fw as `crates/fw-browser-*` (history kept), expose it as `fw browser ...` and through the fw MCP server, make the lite engine (Obscura) a headless WebAssembly + WebGPU (wgpu, not Dawn) browser measured against Chrome headless, document fw as the core of Aphrody Labs, repoint siblings, then archive the `browser` repo.
