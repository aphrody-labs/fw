# Queued lot: apply modern-web guidance everywhere (phase 2)

Source request (2026-11-21, `/aphrody:modern-web`): "apply all, anywhere in ay, aphrody, fw".

## Goal

Every web surface follows the cited guidance in the `aphrody:modern-web` skill (Bun, Modern Web Guidance, WebGPU, wasm, WHATWG/W3C specs). Each fix carries a cite (`repo@commit path:line` or `spec (date)`) and a measured before/after.

## Surfaces (inventory first; this list is a starting point)

- `aphrody/site/` (generator and pages): WebGPU wallpaper, inline SVG, springs, zero requests.
- The web desktop loader HTML generated by `aphrody/tooling/bun/web-build.ts` (wasm streaming compile, content-type, cache headers in the Worker `.cloudflare/aphrody-worker/src/web.ts`).
- Cloudflare Workers in aphrody (`.cloudflare/`), fw (`cloudflare/material-cdn`) and ay.
- Bun HTTP servers and Bun scripts in all three repos: Bun APIs before node:* and npm.
- Any HTML, CSS or JS in ay `packages/` and `apps/`.

## Method

1. For each surface, run `bun plugins/aphrody/skills/modern-web/scripts/query.ts "<topic>" --domain <bun|mwg|webgpu|wasm|specs>`, and `bunx modern-web-guidance@latest search "<topic>"` for HTML, CSS and JS.
2. Record the findings per file with cites, in `docs/reviews/modern-web-<date>.md`.
3. Fix by path. Use `site-perf.ts` and `web-size.ts` (aphrody `tooling/bun/`) as the measuring gates. Lighthouse runs through the `web-quality` skill.

## Gate

An independent re-run of the measuring scripts on the pushed SHAs shows no regression and the recorded gains. Zero runtime requests stays zero on the site.

## Ordering

After the Phase 1 monorepo merge, so paths are final; or earlier for surfaces the merge does not move.
