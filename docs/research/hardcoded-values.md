# Hardcoded colors, user-facing strings and icon names (measurement)

Goal: no color, text or icon name is written as a literal outside the token, catalog and theme files; everything comes from `product.toml` [brand] through `fw-m3`, the locale catalogs, the material-cdn icon sets and the theme directories (`crates/fw-theme`, `docs/architecture/theme-layer.md`).

Tool: `tools/hardcoded.ts`; rules and the allowlist (the only place that declares which files may hold literals) are in `tools/hardcoded.toml`. It reads the blobs of a commit (`--rev`), removes comments, skips `#[cfg(test)]` modules, tests, fixtures, vendored trees, blocks generated by `fw-m3 css --write` and generated sites, and counts:

- color: hex literals, `rgb(`/`rgba(`/`hsl(`/`oklch(` with numeric arguments, named colors in color properties, Kotlin `Color(0x..)` and `Color.Red`;
- string: display text passed to UI constructors and builders (gpui `Label::new`, `.tooltip(`), text nodes of HTML, JSX and JS template literals, `title`/`placeholder`/`aria-label`/`alt`, Kotlin `Text(` and `contentDescription =`;
- icon: `icon`/`glyph` keys, `.svg`/`icons/` path literals, Material Symbols ligature elements, Kotlin `Icons.*`.

The heuristics are conservative and comparable between commits; they are a measure, not an audit of every text.

## Commands

```
bun tools/hardcoded.ts --rev <commit> --by area --top 20     # counts of a commit
bun tools/hardcoded.ts --rev <commit> --by unit --top 400    # per crate or package
bun tools/hardcoded.ts --rev <commit> --hits --only <path>   # every literal with its line
bun tools/hardcoded.ts --check                               # CI: fails when a file is above the baseline
bun tools/hardcoded.ts --update-baseline --rev <commit>      # after a reduction
```

CI runs `--check` in the `hardcoded` job of `.github/workflows/ci.yml` and as the `hardcoded` lane of `cargo xtask ci`. The baseline `docs/research/hardcoded-baseline.tsv` is per file: existing debt does not fail the build, any increase or a new file with literals does.
