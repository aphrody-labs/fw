## About each crate

- **toml**: A native Rust encoder and decoder of TOML-formatted files and streams. Provides implementations of the standard Serialize/Deserialize traits for TOML data to facilitate deserializing and serializing Rust structures. 
- **toml\_edit**: Yet another format-preserving TOML parser.
- **quick-xml**: High performance xml reader and writer
- **tree-sitter**: Rust bindings to the Tree-sitter parsing library
- **zerocopy**: Zerocopy makes zero-cost memory manipulation effortless. We write "unsafe" so you don't have to.
- **pest**: The Elegant Parser
- **pest\_derive**: pest's derive macro
- **winnow**: A byte-oriented, zero-copy, parser combinators library
- **tree-sitter-language**: The tree-sitter Language type, used by the library and by language implementations
- **zbus**: API for D-Bus communication and its wire format
- **skrifa**: Metadata reader and glyph scaler for OpenType fonts.
- **calamine**: An Excel/OpenDocument Spreadsheet reader and deserializer in pure Rust
- **comrak**: A 100% CommonMark-compatible GitHub Flavored Markdown parser and formatter
- **read-fonts**: Reading OpenType font files.
- **chumsky**: A parser library for humans with powerful error recovery
- **toml\_datetime**: A TOML-compatible datetime type
- **lalrpop-util**: Runtime library for parsers generated by LALRPOP
- **compact\_str**: A memory efficient string type that transparently stores strings on the stack, when possible
- **strum**: Helpful macros for working with enums and strings
- **lalrpop**: convenient LR(1) parser generator
- **serde\_spanned**: Serde-compatible spanned Value
- **pest\_meta**: pest meta language parser and validator
- **atoi**: Parse integers directly from \`\[u8\]\` slices in safe code
- **toml\_parser**: Yet another format-preserving TOML parser.
- **write-fonts**: Writing font files.
