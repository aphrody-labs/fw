## About each crate

- **egui**: An easy-to-use immediate mode GUI that runs on both web and native
- **eframe**: egui framework - write GUI apps that compiles to web and/or natively
- **egui\_extras**: Extra functionality and widgets for the egui GUI library
- **egui-wgpu**: Bindings for using egui natively using the wgpu library
- **egui-winit**: Bindings for using egui with winit
- **egui\_glow**: Bindings for using egui natively using the glow library
- **rapier3d**: 3-dimensional physics engine in Rust.
- **softbuffer**: Cross-platform software buffer
- **egui\_dock**: Docking system for egui - an immediate-mode GUI library for Rust
- **rapier2d**: 2-dimensional physics engine in Rust.
- **sdl3-sys**: Low level Rust bindings for SDL 3
- **simple-easing**: Set of simple easing functions
- **aeronet\_io**: IO abstraction primitives for \`aeronet\`
- **kira**: Expressive audio library for games
- **parry3d**: 3 dimensional collision detection library in Rust.
- **avian3d**: An ECS-driven physics engine for the Bevy game engine
- **lightyear**: Server-client networking library for the Bevy game engine with modular architecture
- **bevy\_asset\_loader**: Bevy plugin for asset loading
- **bevy\_kira\_audio**: Bevy plugin for dynamic audio
- **rapier3d-f64**: 3-dimensional physics engine in Rust.
- **parry3d-f64**: 3 dimensional collision detection library in Rust. 64-bits precision version.
- **glamx**: Extensions for glam: Pose2, Pose3, Rot2, and matrix utilities.
- **tracel-ash**: Vulkan bindings for Rust
- **parry2d**: 2 dimensional collision detection library in Rust.
- **bevy-inspector-egui**: Inspector plugin for the bevy game engine
