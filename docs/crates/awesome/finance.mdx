## About each crate

- **ibapi**: An unofficial Rust client for the Interactive Brokers TWS API: market data, orders, and account data, with async (Tokio) and blocking clients for TWS and IB Gateway.
- **nautilus-core**: Core functionality for the Nautilus trading engine
- **nautilus-model**: Domain model for the Nautilus trading engine
- **nautilus-common**: Common functionality and machinery for the Nautilus trading engine
- **polymarket\_client\_sdk\_v2**: Polymarket CLOB (Central Limit Order Book) API client SDK
- **optionstratlib**: OptionStratLib facade: option pricing, Greeks, option chains, P&L, risk, strategies, simulation, backtesting and charts for trading and strategy development, re-exported from its nine component crates with one feature per capability.
- **nautilus-system**: System orchestration for the Nautilus trading engine
- **nautilus-network**: Network communication machinery for the Nautilus trading engine
- **nautilus-live**: Core live trading components and machinery for the Nautilus trading engine
- **orderbook-rs**: A high-performance, lock-free price level implementation for limit order books in Rust. This library provides the building blocks for creating efficient trading systems with support for multiple order types and concurrent access patterns.
- **wickra-core**: Core streaming-first technical indicators engine for the Wickra library
- **nautilus-execution**: Core execution machinery for the Nautilus trading engine
- **financial\_types**: Core financial type definitions for trading systems: asset types, trading actions, position sides, and option styles.
- **quickfix**: High level binding to quickfix C++ library
- **databento**: Official Databento client library
- **uniswap-v3-sdk**: Uniswap V3 SDK for Rust
- **wickra-backtest-core**: Streaming-native backtest engine core (strategy spec, rules, execution, portfolio) built on wickra-core.
- **x402-types**: Core types for x402 payments: chain identifiers, protocol messages, and facilitator traits
- **iso10383-types**: ISO 10383 Types
- **nautilus-serialization**: Serialization functionality for the Nautilus trading engine
- **positive**: A type-safe wrapper for guaranteed positive decimal values
- **nautilus-trading**: Strategy machinery and controllers for the Nautilus trading engine
- **nautilus-portfolio**: Portfolio components and functionality for the Nautilus trading engine
- **optionstratlib-core**: Core domain model of OptionStratLib: options, positions, legs, trades, checked Decimal helpers and their errors. Re-exported by the optionstratlib facade on every feature set.
- **optionstratlib-pricing**: Option pricing models, Greeks and implied volatility of OptionStratLib, on Decimal and Positive boundaries. Re-exported by the optionstratlib facade under its \`pricing\` feature.
