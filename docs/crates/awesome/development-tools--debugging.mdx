## About each crate

- **log**: A lightweight logging facade for Rust 
- **env\_logger**: A logging implementation for \`log\` which is configured via an environment variable. 
- **defmt**: A highly efficient logging framework that targets resource-constrained devices, like microcontrollers
- **tracing**: Application-level tracing for Rust. 
- **opentelemetry**: OpenTelemetry API for Rust
- **opentelemetry-otlp**: Exporter for the OpenTelemetry Collector
- **tracing-subscriber**: Utilities for implementing and composing \`tracing\` subscribers. 
- **tracing-opentelemetry**: OpenTelemetry integration for tracing
- **opentelemetry-semantic-conventions**: Semantic conventions for OpenTelemetry
- **opentelemetry-proto**: Protobuf generated files and transformations.
- **env\_filter**: Filter log events using environment variables 
- **flexi\_logger**: An easy-to-configure and flexible logger that writes logs to stderr or stdout and/or to files. It allows custom logline formats, and it allows changing the log specification at runtime. It also allows defining additional log streams, e.g. for alert or security messages.
- **addr2line**: A cross-platform symbolication library written in Rust, using \`gimli\`
- **tracing-appender**: Provides utilities for file appenders and making non-blocking writers. 
- **metrics**: A lightweight metrics facade.
- **gimli**: A library for reading and writing the DWARF debugging format.
- **opentelemetry-prometheus**: Prometheus exporter for OpenTelemetry
- **goblin**: An impish, cross-platform, ELF, Mach-o, and PE binary parsing and loading crate
- **tracing-core**: Core primitives for application-level tracing. 
- **metrics-exporter-prometheus**: A metrics-compatible exporter for sending metrics to Prometheus.
- **opentelemetry-stdout**: An OpenTelemetry exporter for stdout
- **pyo3-log**: Logging bridge from pyo3 native extension to python
- **fastrace**: A high-performance timeline tracing library for Rust
- **blazesym**: blazesym is a library for address symbolization and related tasks.
- **metrics-util**: Helper types/functions used by the metrics ecosystem.
