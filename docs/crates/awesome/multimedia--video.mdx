## About each crate

- **symphonia**: Pure Rust media container and audio decoding library.
- **yuv**: High performance utilities for YUV format handling and conversion.
- **openh264**: Idiomatic bindings for OpenH264.
- **v\_frame**: Video Frame data structures, originally part of rav1e
- **openh264-sys2**: Low-level bindings for OpenH264.
- **pic-scale**: High performance image scaling
- **h264-reader**: Reader for H264 bitstream syntax
- **rust\_h265**: Pure Rust H.265/HEVC video decoder: Main, Main 10 and the 4:2:0 / 4:4:4 range-extension profiles up to 12-bit, multithreaded
- **mpeg-ts**: MPEG-2 Transport Stream framing (ITU-T H.222.0 / ISO/IEC 13818-1): TS packet, adaptation field, PCR, PSI section reassembly + packetisation, resync. no\_std.
- **core-video**: Safe bindings to CoreVideo framework
- **transmux**: Any-to-any media container muxing hub: demux TS, fMP4/CMAF, MPEG-PS, WebM, FLV, or RTMP into one neutral IR and mux to CMAF/fMP4, progressive MP4, TS, DASH, low-latency DASH, HLS, low-latency HLS, Smooth Streaming, or RTMP. CENC/CBCS encrypt+decrypt, SSAI splice, RTP/RTCP, and an fMP4/CMAF conformance validator; parses codec config headers only, samples stay opaque. no\_std + alloc, except the XML manifest paths (DASH/Smooth/PlayReady), which need the std feature.
- **oxideav-pixfmt**: Pure-Rust pixel-format conversions, palette quantisation, and dithering — the oxideav framework's shared pixfmt layer
- **re\_mp4**: MP4 parser
- **rusty\_h264-common**: Shared primitives for the rusty\_h264 pure-Rust H.264 codec: bitstream I/O, Exp-Golomb, NAL/Annex-B, transforms, intra prediction, motion compensation and deblocking. forbid(unsafe). BSD-2.
- **mediatime**: Exact-integer rational time types for media pipelines — FFmpeg-style Timebase, Timestamp, and TimeRange. no\_std, zero dependencies, const fn.
- **mediaframe**: A common media-stream descriptor vocabulary (pixel-format, colour, and frame metadata for video — audio/subtitle to follow) for media processing pipelines.
- **rust\_h264**: Pure Rust H.264/AVC video decoder
- **muxide**: Minimal-dependency pure-Rust MP4 muxer for recording applications. Includes CLI tool and library API.
- **video-rs**: High-level video toolkit based on ffmpeg.
- **oxideav-vp8**: Pure-Rust VP8 video codec — orphan-rebuild scaffold pending clean-room re-implementation.
- **rusty\_h264-encoder**: Pure-Rust H.264 encoder (Baseline/Main: intra, P-frames, quarter-pel ME, CABAC, adaptive quantization, ABR rate control) — bit-exact under ffmpeg across QP 0-51. forbid(unsafe) core; portable Rust SIMD on by default. BSD-2.
- **oxideav-av1**: Pure-Rust AV1 codec — orphan-rebuild scaffold pending clean-room re-implementation.
- **oxideav-h265**: Pure-Rust H.265 / HEVC (ITU-T H.265 \| ISO/IEC 23008-2) bitstream parser + decoder scaffold for oxideav
- **rusty\_h264-decoder**: Pure-Rust H.264 decoder (Baseline + B-slices + most of High profile, CAVLC + CABAC) — bit-exact vs Cisco openh264, pixel-exact vs ffmpeg, fuzzed panic-free. forbid(unsafe) core; portable Rust SIMD on by default. BSD-2.
- **oxideav-h264**: Pure-Rust H.264 / AVC (ITU-T H.264 \| ISO/IEC 14496-10) codec for oxideav — under spec-driven rewrite, no decode/encode functionality yet
