## About each crate

- **toml**: A native Rust encoder and decoder of TOML-formatted files and streams. Provides implementations of the standard Serialize/Deserialize traits for TOML data to facilitate deserializing and serializing Rust structures. 
- **toml\_edit**: Yet another format-preserving TOML parser.
- **config**: Layered configuration system for Rust applications.
- **plist**: A rusty plist parser. Supports Serde serialization.
- **serde-saphyr**: YAML (de)serializer for Serde, emphasizing panic-free parsing, fast builds and good error reporting. Supports properties, include, tag and comment capture
- **toml\_datetime**: A TOML-compatible datetime type
- **serde\_spanned**: Serde-compatible spanned Value
- **cedar-policy**: Cedar is a language for defining permissions as policies, which describe who should have access to what.
- **toml\_parser**: Yet another format-preserving TOML parser.
- **guppy**: Track and query Cargo dependency graphs.
- **gix-config**: A git-config file parser and editor from the gitoxide project
- **cedar-policy-core**: Core implementation of the Cedar policy language
- **tor-config**: Low-level configuration for the Arti Tor implementation
- **configparser**: A simple configuration parsing utility with no dependencies that allows you to parse INI and ini-style syntax. You can use this to write Rust programs which can be customized by end users easily.
- **noyalib**: A pure Rust YAML library with zero unsafe code and full serde integration
- **toml-span**: Toml parser and deserializer that preserves span information
- **cedar-policy-formatter**: Policy formatter for the Cedar Policy Language.
- **test-log**: A replacement of the #\[test\] attribute that initializes logging and/or tracing infrastructure before running tests. 
- **greentic-types**: Shared primitives for Greentic: TenantCtx, InvocationEnvelope, NodeError, ids.
- **tor-persist**: Persistent state for the Arti Tor implementation
- **tor-config-path**: Low-level file path handling for configuration of the Arti Tor implementation
- **yaml-merge-keys**: Implementation of the YAML merge key extension.  http://yaml.org/type/merge.html 
- **etcetera**: An unopinionated library for obtaining configuration, data, cache, & other directories
- **sequential-storage**: A crate for storing data in flash with minimal erase cycles.
- **shikumi**: Shikumi (仕組み) — config discovery, hot-reload, and ArcSwap store for Nix-managed desktop apps
