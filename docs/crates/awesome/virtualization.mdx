## About each crate

- **landlock**: Safe abstraction for Linux Landlock sandboxing
- **wasmi**: WebAssembly interpreter
- **wasmi\_core**: Core primitives for the wasmi WebAssembly interpreter
- **wasmi\_collections**: Specialized data structures for the Wasmi interpreter
- **wasmi\_ir**: WebAssembly interpreter internal bytecode representation
- **wasmi\_wasi**: WASI library support for the wasmi interpreter
- **tinywasm**: A tiny WebAssembly interpreter
- **pktkit**: Zero-copy L2/L3 packet handling toolkit. Frames, packets, hubs, adapters, NAT, virtual TCP/IP, WireGuard, OpenVPN, QEMU networking, TUN/TAP, AF\_XDP — all gated behind opt-in cargo features.
- **wasmi\_c\_api\_macros**: Support macros for the \`wasmi\_c\_api\_impl\` crate
- **tinywasm-types**: Shared runtime, module, and archive types for TinyWasm
- **virtio-accel-core**: Transport-independent accelerator lifecycle traits
- **soroban-wasmi**: Soroban fork of Parity WebAssembly interpreter
- **virtio-accel-transport**: Portable descriptor-chain and virtqueue port contracts
- **tinywasm-parser**: Parser and lowering pipeline for TinyWasm
- **wasmi\_c\_api\_impl**: C bindings for the Wasmi WebAssembly interpreter
- **virtio-accel-proto**: Pointer-free portable virtio accelerator protocol 1.0 ABI
- **draupnir**: Draupnir — the nordisk boot/provisioning library: fire up a runtime from one BootSpec across three backends (KVM via tunnr · OCI container · Redfish bare-metal virtual-media) and drive its power lifecycle. Odin's ring that drips eight identical copies → boot a fleet of identical machines from one ISO.
- **virtio-accel-tosa**: Safe, bounded TOSA artifacts and zero-copy graph views for virtio-accel
- **virtio-accel-device**: Transport-neutral virtio accelerator device state
- **netavark**: A container network stack
- **isothrum-runner**: The Isothrum runner: executes the run manifest Isoloom writes next to a target's files (lifecycle, state and locks, drivers, checks, events).
- **isoloom-compose**: The Docker Compose backend of Isoloom (docker, hosted).
- **isoloom-vagrant**: The Vagrant backends of Isoloom (vagrant, docker-vm, hybrid).
- **nvx**: NVX's library of mechanisms and value types for OpenVMM microVMs: launch, snapshots and restores, verified connections, and the guest's side of capture and guest restore
- **ankaios\_sdk**: Eclipse Ankaios Rust SDK - provides a convenient Rust interface for interacting with the Ankaios platform.
