## About each crate

- **hf-xet**: Client library and tooling for the Hugging Face Xet data storage system.
- **xet-core-structures**: Core data structures including MerkleHash, metadata shards, and Xorb objects.
- **xet-runtime**: Async runtime, configuration, logging, and utility infrastructure for the Hugging Face Xet client tools.
- **xet-client**: Client library for communicating with Hugging Face Xet storage servers.  Use through the hf-xet crate.
- **xet-data**: Data processing pipeline for chunking, deduplication, and file reconstruction; used in the Hugging Face Xet client tools.  Intended to be used through the API in the hf-xet package.
- **bamboo-agent-core**: Core agent abstractions and execution primitives for the Bamboo agent framework
- **rpi-ai**: Unified multi-provider LLM types + streaming, Rust port of pi-ai
- **rpi-agent**: Agent runtime + loop, Rust port of pi-agent-core core layer
- **rpi-tools**: Built-in agent tools (read/write/edit/bash/grep/find/ls) + ExecutionEnv, Rust port of pi harness tools
- **anno**: NER, coreference resolution, relation extraction, PII detection, and zero-shot entity types
- **zuoer**: Domain-neutral run segmenter: the Silero-derived hysteresis state machine that turns any frame-probability sequence into contiguous runs with mean/peak aggregates — one instance per class for sound-event detection. Over it sits a backend-agnostic voice-activity-detection (VAD) shell: the VadBackend seam and the Speech\* names. The model, inference runtime, and audio I/O live in the backend crate.
- **rpi-harness**: Session tree + JSONL persistence + compaction + AgentHarness loop, Rust port of pi harness layer
- **decapod**: Decapod is a Rust-built governance runtime for AI agents: repo-native state, enforced workflow, proof gates, safe coordination.
- **ese**: Embedded Static Embeddings: runtime for compiled-in static embedding models
- **bamboo-sdk**: Ergonomic top-level Agent SDK facade for the Bamboo agent framework
- **cf-gears-mini-chat-sdk**: SDK for mini-chat: policy plugin traits, models, and errors
- **onde**: On-device AI inference: LLM chat, tool calling and image generation, on every platform.
- **bamboo-agent**: A fully self-contained AI agent backend framework with built-in web services, multi-LLM provider support, and comprehensive tool execution
- **rpi-cli**: Terminal coding-agent CLI (the \`rpi\` binary) built on the rpi-\* library crates
- **mcp-session**: Bounded session management for MCP servers — max sessions, FIFO eviction, rate limiting
- **cf-gears-mini-chat**: mini-chat gear: multi-tenant AI chat
- **elicitation**: Conversational elicitation of strongly-typed Rust values via MCP
- **lineprior**: Explainable action ranking from historical sequences, with confidence, context backoff, evaluation, and tuning.
- **hatchling-memory**: Broker-owned durable memory: scoped user/project/session items with explicit retention, durable session records, and an append-only context log. Memory is recalled data, never instructions.
- **talin-provider**: A strongly-typed Rust client and type definitions for LLM provider APIs
