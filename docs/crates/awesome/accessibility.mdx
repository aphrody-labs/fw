## About each crate

- **egui\_kittest**: Testing library for egui based on kittest and AccessKit
- **atspi**: Pure-Rust, zbus-based AT-SPI2 protocol implementation.
- **uiautomation**: UI Automation Framework for Windows
- **tqdm**: Python tqdm in Rust
- **egui\_inspection**: Protocol and egui::Plugin for inspection of egui apps
- **kittest**: Automated GUI testing using AccessKit
- **atspi-common**: Primitive types used for sending and receiving Linux accessibility events.
- **atspi-proxies**: AT-SPI2 proxies to query or manipulate UI objects
- **floravox-g2p**: Hybrid grapheme-to-phoneme: memory-mapped FST lexicons with pluggable OOV fallback
- **anda\_db\_tfs**: A full-text search library using the BM25 ranking algorithm in Rust.
- **clapdown**: Generate well-structured Markdown documentation from a clap CLI.
- **a11y-dom**: Document model abstraction for accessibility rules: a DOM-shaped tree trait plus opt-in capability tiers for semantics, rendering and interaction.
- **floravox-ssml**: Zero-copy SSML parser with byte- and char-exact source span tracking
- **a11y-report**: Shared finding and report model for accessibility tooling: four outcome states, severity, WCAG mapping and a stable JSON contract.
- **snora**: iced engine for the Snora GUI framework. Consumes snora-core vocabulary.
- **mid**: Creating a Machine ID hash for MacOS/Windows/Linux/iOS
- **rightkit-automation**: Brand-neutral desktop automation: observe and act on any app (macOS AX, Windows UIA) through a four-tier input ladder with safety, focus guard, and evidence receipts.
- **atspi-connection**: A method of connecting, querying, sending and receiving over AT-SPI.
- **floravox-core**: ONNX synthesis orchestration: duration folding, sample-accurate event timeline, streaming API
- **accname**: WAI-ARIA Accessible Name and Description Computation in Rust, generic over the document model.
- **a11y-rules**: Accessibility rules generic over the document model: one rule set for build-time, CI and in-page surfaces.
- **perceive-color**: WCAG contrast, APCA, OKLCH, and accessible palette generation
- **anda\_db\_hnsw**: A high-performance vector search library in Rust.
- **anda\_db\_btree**: A B-tree index library in Rust.
- **telar-semantics-core**: What a thing in a Telar interface is: the roles a screen reader, a document and a terminal all describe the same box with.
