## About each crate

- **mavlink**: Implements the MAVLink data interchange format for UAVs.
- **mavlink-core**: Implements the MAVLink data interchange format for UAVs.
- **mavlink-bindgen**: Library used by rust-mavlink.
- **sguaba**: Hard to misuse rigid body transforms (aka "spatial math") for engineers with other things to worry about than linear algebra.
- **deep\_causality**: Computational causality library. Provides causality graph, collections, context and causal reasoning.
- **spacepackets**: Generic implementations for various CCSDS and ECSS packet standards
- **world\_magnetic\_model**: Rust implementation of the NOAA World Magnetic Model (WMM).
- **sift\_error**: Crate-specific Sift errors
- **minikalman**: A microcontroller targeted Kalman filter implementation
- **satkit**: Satellite Toolkit
- **fusion-ahrs**: Rust port of xioTechnologies' Fusion AHRS C library — sensor fusion for gyroscope, accelerometer, and magnetometer with no\_std support.
- **rsfitsio**: Rust bindings for the CFITSIO library, providing access to FITS files.
- **sift\_connect**: A convenient and opinionated way to connect to the Sift API
- **spicekit**: Pure-Rust reader for NASA/NAIF SPICE kernel formats (DAF, SPK, PCK, text kernels). Independent of the CSpice toolkit.
- **sift\_rs**: General Rust client library for the Sift API
- **vita49**: vita49 is a crate for parsing and creating packets compatible with the ANSI/VITA-49.2-2017 standard. 
- **qtty**: Strongly typed physical and astronomical quantities.
- **deep\_causality\_context**: Context hypergraph, context node types, and contextuable traits for DeepCausality.
- **geo3d**: 3D positions on Earth, made simple. Convert GPS (geodetic) coordinates to ECEF, local ENU/NED frames, UTM and heights above sea level, then find look angles, distances, areas and line of sight. Exact, tested, no dependencies, and runs on microcontrollers (no\_std).
- **sift\_pbfs**: PBFS (Protobuf File Stream) format for reading and writing protobuf messages to disk
- **vita49\_macros**: vita49\_macros provides procedural macros for the vita49 crate 
- **sift\_stream**: A robust Sift telemetry streaming library
- **irox-units**: Physical Quantities, Units, & Reference Frames Library
- **sgp4**: A pure Rust implementation of the SGP4 algorithm for satellite propagation
- **siderust-archive**: Reusable Rust bindings for the Siderust Archive: manifests, checksums, provenance, and runtime download of scientific datasets (IERS time data, kernels, planetary theories).
