## About each crate

- **egui\_plot**: Immediate mode plotting for the egui GUI library
- **skia-safe**: Safe Skia Bindings for Rust
- **pdfium-render**: A high-level idiomatic Rust wrapper around Pdfium, the C++ PDF library used by the Google Chromium project.
- **rerun**: The Rerun Rust SDK: log images, point clouds, etc, and visualize them effortlessly
- **tabled**: An easy to use library for pretty print tables of Rust \`struct\`s and \`enum\`s.
- **inferno**: Rust port of the FlameGraph performance profiling tool suite
- **skia-bindings**: Skia Bindings for Rust
- **krates**: Create graphs of crates gathered from cargo metadata
- **tokei**: Count your code, quickly.
- **termtree**: Visualize tree-like data on the command-line
- **merman**: Parity-focused, headless Rust implementation of Mermaid for parsing, layout, and rendering.
- **re\_sdk**: Rerun logging SDK
- **merman-core**: Mermaid parser + semantic model (headless; parity-focused).
- **colorgrad**: Color scales library for data visualization, charts, games, generative art and others.
- **flamegraph**: A simple cargo subcommand for generating flamegraphs, using inferno under the hood
- **mermaid-text**: Render Mermaid diagrams as Unicode box-drawing text — no browser, no image protocols, pure Rust
- **tui-piechart**: A customizable pie chart widget for Ratatui TUI applications
- **egui\_json\_tree**: An interactive JSON tree visualiser for egui, with search and highlight functionality.
- **dugong**: Dagre-compatible graph layout algorithms (port of dagrejs/dagre).
- **merman-render**: Headless layout + SVG renderer for Mermaid (parity-focused; upstream SVG goldens).
- **aprender-viz**: SIMD/GPU/WASM-accelerated visualization library for data science and ML
- **bevy-inspector-egui**: Inspector plugin for the bevy game engine
- **criterion-plot**: Criterion's plotting library
- **merman-ascii**: Terminal-friendly ASCII and Unicode renderer for Mermaid typed models.
- **kuva**: Scientific plotting library in Rust with various backends.
