## About each crate

- **defmt**: A highly efficient logging framework that targets resource-constrained devices, like microcontrollers
- **zerocopy**: Zerocopy makes zero-cost memory manipulation effortless. We write "unsafe" so you don't have to.
- **icu\_properties**: Definitions for Unicode properties
- **ctor**: Global, no\_std-compatible constructors for all platforms that run before main (like C/C++ \_\_attribute\_\_((constructor)))
- **icu\_provider**: Trait and struct definitions for the ICU data provider
- **portable-atomic**: Portable atomic types including support for 128-bit atomics, atomic float, etc. 
- **cortex-m**: Low level access to Cortex-M processors
- **icu\_locale\_core**: API for managing Unicode Language and Locale Identifiers
- **icu\_normalizer**: API for normalizing text into Unicode Normalization Forms
- **rhai**: Embedded scripting for Rust
- **icu\_locale**: API for Unicode Language and Locale Identifiers canonicalization
- **burn**: Flexible and Comprehensive Deep Learning Framework in Rust
- **icu\_collections**: Collection of API for use in ICU libraries.
- **icu\_segmenter**: Unicode line breaking and text segmentation algorithms for text boundaries analysis
- **cortex-m-rt**: Minimal runtime / startup for Cortex-M microcontrollers
- **r-efi**: UEFI Reference Specification Protocol Constants and Definitions
- **icu\_calendar**: Date APIs for Gregorian and non-Gregorian calendars
- **portable-atomic-util**: Synchronization primitives built with portable-atomic. 
- **bitvec**: Addresses memory by bits, for packed collections and bitfields
- **icu\_properties\_data**: Data for the icu\_properties crate
- **icu\_collator**: API for comparing strings according to language-dependent conventions
- **icu\_normalizer\_data**: Data for the icu\_normalizer crate
- **icu\_decimal**: API for formatting basic decimal numbers in a locale-sensitive way
- **icu\_plurals**: Unicode Plural Rules categorizer for numeric input
- **icu\_casemap**: Unicode case mapping and folding algorithms
