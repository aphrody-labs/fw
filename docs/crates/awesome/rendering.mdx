## About each crate

- **bevy**: A refreshingly simple data-driven game engine and app framework
- **vello\_cpu**: A CPU-based renderer for Vello, optimized for SIMD and multithreaded execution.
- **vello\_common**: Core data structures and utilities shared across the Vello rendering, including geometry processing and tiling logic.
- **vello**: A GPU compute-centric 2D renderer.
- **sdl2**: SDL2 bindings for Rust
- **kasuari**: A rust layout solver for GUIs, based on the Cassowary algorithm. A fork of the unmaintained cassowary-rs crate with improvments and bug fixes. Kasuari is the indonesian name for the cassowary bird. 
- **softbuffer**: Cross-platform software buffer
- **vello\_encoding**: Vello types that represent the data that needs to be rendered.
- **encase**: Provides a mechanism to lay out data into GPU buffers ensuring WGSL's memory layout requirements are met
- **sdl3-sys**: Low level Rust bindings for SDL 3
- **pixels**: A tiny library providing a GPU-powered pixel frame buffer.
- **tiny-skia**: A tiny Skia subset ported to Rust.
- **vello\_shaders**: Vello infrastructure to preprocess and cross-compile shaders at compile time.
- **meshopt**: Rust ffi bindings and idiomatic wrapper for mesh optimizer
- **bevy\_internal**: An internal Bevy crate used to facilitate optional dynamic linking via the 'dynamic\_linking' feature
- **i-slint-renderer-skia**: Skia based renderer for Slint
- **stet-graphics**: Display-list IR, ICC colour management, and graphics types — a stable target for custom PostScript and PDF renderers
- **openusd**: Rust native USD library
- **sdl3**: Bindings to SDL3, a cross-platform library to abstract the platform-specific details for building applications.
- **i-slint-renderer-femtovg**: FemtoVG based renderer for Slint
- **tui-piechart**: A customizable pie chart widget for Ratatui TUI applications
- **sdl2-sys**: Raw SDL2 bindings for Rust, used internally rust-sdl2
- **takumi**: Render images, animations, and SVG from HTML, CSS, or node trees. No headless browser.
- **horned-owl**: Library for OWL Ontologies
- **velato**: A Lottie integration for vello.
