## About each crate

- **landlock**: Safe abstraction for Linux Landlock sandboxing
- **ashpd**: XDG portals wrapper in Rust using zbus
- **oo7**: James Bond went on a new mission and this time as a Secret Service provider
- **sev**: Library for AMD SEV
- **selinux**: Flexible Mandatory Access Control for Linux
- **perf-event-open-sys**: Unsafe, direct bindings for Linux's perf\_event\_open system call, with associated types and constants. 
- **i-slint-backend-linuxkms**: Linux KMS/DRM backend for Slint, to run full-screen on embedded Linux without a windowing system
- **usb-gadget**: Expose standard or fully custom USB peripherals (gadgets) through a USB device controller (UDC) on Linux.
- **nmstate**: Library for networking management in a declarative manner
- **selinux-sys**: Flexible Mandatory Access Control (MAC) for Linux
- **drmkit-core**: Core DRM/KMS device access for drmkit: device handles, property caching, and atomic requests.
- **nlink**: Async netlink library for Linux network configuration
- **libublk-rs-sys**: Low-level FFI bindings for Linux ublk (userspace block device) kernel interface
- **bpf-linker**: BPF static linker
- **drmkit-fmt**: DRM format and format-modifier support for drmkit: IN\_FORMATS tables, modifier classification, and bandwidth cost.
- **xdp**: AF\_XDP socket support without C dependencies
- **nlink-macros**: Proc-macro derives for the nlink Linux-netlink library — typed GENL family / command / attribute codecs
- **bluez-async**: An async wrapper around the D-Bus interface of BlueZ (the Linux Bluetooth daemon), supporting GATT client (central) functionality.
- **devicemapper**: A library for using Linux device mapper
- **linux-targets**: Linux target selection: distribution presets with glibc and kernel floors
- **libcryptsetup-rs**: High level Rust bindings for libcryptsetup
- **kernel-abi-tools**: Linux kernel ABI data and seccomp profiles that simulate older kernels when testing Rust binaries
- **drmkit-planes**: Display-plane registry, layer model, and the bipartite plane allocator for drmkit.
- **drmkit-dumb**: DRM dumb buffers for drmkit: GPU-free, CPU-mappable scanout surfaces with lifetime mmaps.
- **drmkit-log**: Diagnostic surface for drmkit: process-wide level, installable sink, and per-category channels.
