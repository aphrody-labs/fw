## About each crate

- **rustix**: Safe Rust bindings to POSIX/Unix/Linux/Winsock-like syscalls
- **time**: Date and time library. Fully interoperable with the standard library. Mostly compatible with #!\[no\_std\].
- **jiff**: A date-time library that encourages you to jump into the pit of success.  This library is heavily inspired by the Temporal project. 
- **chrono**: Date and time library for Rust
- **humantime**: A parser and formatter for std::time::\{Duration, SystemTime\}
- **jiff-tzdb**: The entire Time Zone Database embedded into your binary.
- **time-macros**:     Procedural macros for the time crate.     This crate is an implementation detail and should not be relied upon directly. 
- **temporal\_rs**: Temporal in Rust is an implementation of the TC39 Temporal Builtin Proposal in Rust.
- **croner**: Fully-featured, lightweight, and efficient Rust library designed for parsing and evaluating cron patterns
- **iana-time-zone**: get the IANA time zone for the current system
- **icalendar**: Strongly typed iCalendar builder and parser.
- **jiff-static**: Create static TimeZone values for Jiff (useful in core-only environments).
- **time-core**: This crate is an implementation detail and should not be relied upon directly.
- **jiff-sqlx**: Integration for Jiff with SQLx.
- **jiff-core**: Low level datetime primitives for the Jiff library.
- **tick**: Provides primitives to interact with and manipulate machine time.
- **nuid**: A highly performant unique identifier generator.
- **jiff-icu**: Conversion routines between Jiff and ICU4X.
- **chrono-tz**: TimeZone implementations for chrono from the IANA database
- **tzf-rs**: Fast convert longitude,latitude to timezone name.
- **iso8601**: Parsing ISO8601 dates using nom
- **web-time**: Drop-in replacement for std::time for Wasm in browsers
- **fugit**: Time library for embedded targets with ease-of-use and performance first.
- **speedate**: Fast and simple datetime, date, time and duration parsing
- **jiff-tzdb-platform**: The entire Time Zone Database embedded into your binary for specific platforms.
