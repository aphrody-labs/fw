## About each crate

- **bytes**: Types and traits for working with bytes
- **uuid**: A library to generate and parse UUIDs.
- **indexmap**: A hash table with consistent order and fast iteration.
- **either**: The enum \`Either\` with variants \`Left\` and \`Right\` is a general purpose sum type with two cases. 
- **smallvec**: 'Small vector' optimization: store up to a small number of items on the stack
- **rustls-pki-types**: Shared types for the rustls PKI ecosystem
- **crossbeam-channel**: Multi-producer multi-consumer channels for message passing
- **der**: Pure Rust embedded-friendly implementation of the Distinguished Encoding Rules (DER) for Abstract Syntax Notation One (ASN.1) as described in ITU X.690 with full support for heapless \`no\_std\`/\`no\_alloc\` targets 
- **rust\_decimal**: Decimal number implementation written in pure Rust suitable for financial and fixed-precision calculations.
- **heapless**: \`static\` friendly data structures that don't require dynamic memory allocation
- **bon**: Next-gen compile-time-checked builder generator, named function's arguments, and more!
- **generic-array**: Generic types implementing functionality of arrays
- **zbus**: API for D-Bus communication and its wire format
- **x509-cert**: Pure Rust implementation of the X.509 Public Key Infrastructure Certificate format as described in RFC 5280 
- **arc-swap**: Atomically swappable Arc
- **crypto-bigint**: Pure Rust implementation of a big integer library which has been designed from the ground-up for use in cryptographic applications. Provides constant-time, \`no\_std\`/\`no\_alloc\`-friendly implementations of modern formulas using const generics. Also includes optional support for heap-backed integers. 
- **crossbeam-utils**: Utilities for concurrent programming
- **hashbrown**: A Rust port of Google's SwissTable hash map
- **alloy-primitives**: Ethereum primitive types
- **num-bigint**: Big integer implementation for Rust
- **fixedbitset**: FixedBitSet is a simple bitset collection
- **zerovec**: Zero-copy vector backed by a byte array
- **roaring**: A better compressed bitset - pure Rust implementation
- **arrayvec**: A vector with fixed capacity, backed by an array (it can be stored on the stack too). Implements fixed capacity ArrayVec and ArrayString.
- **crossbeam-queue**: Concurrent queues
