## About each crate

- **serde\_json**: A JSON serialization file format
- **toml**: A native Rust encoder and decoder of TOML-formatted files and streams. Provides implementations of the standard Serialize/Deserialize traits for TOML data to facilitate deserializing and serializing Rust structures. 
- **url**: URL library for Rust, based on the WHATWG URL Standard
- **serde**: A generic serialization/deserialization framework
- **prost**: A Protocol Buffers implementation for the Rust Language.
- **toml\_edit**: Yet another format-preserving TOML parser.
- **schemars**: Generate JSON Schemas from Rust code
- **base64**: encodes and decodes base64 as bytes or utf8
- **quick-xml**: High performance xml reader and writer
- **serde\_with**: Custom de/serialization functions for Rust's serde
- **zerocopy**: Zerocopy makes zero-cost memory manipulation effortless. We write "unsafe" so you don't have to.
- **encoding\_rs**: A Gecko-oriented implementation of the Encoding Standard
- **bstr**: A string type that is not required to be valid UTF-8.
- **der**: Pure Rust embedded-friendly implementation of the Distinguished Encoding Rules (DER) for Abstract Syntax Notation One (ASN.1) as described in ITU X.690 with full support for heapless \`no\_std\`/\`no\_alloc\` targets 
- **kube**: Kubernetes client and async controller runtime
- **zbus**: API for D-Bus communication and its wire format
- **borsh**: Binary Object Representation Serializer for Hashing 
- **ron**: Rusty Object Notation
- **x509-cert**: Pure Rust implementation of the X.509 Public Key Infrastructure Certificate format as described in RFC 5280 
- **plist**: A rusty plist parser. Supports Serde serialization.
- **calamine**: An Excel/OpenDocument Spreadsheet reader and deserializer in pure Rust
- **data-encoding**: Efficient and customizable data-encoding functions like base64, base32, and hex
- **html-escape**: This library is for encoding/escaping special characters in HTML and decoding/unescaping HTML entities as well.
- **rkyv**: Zero-copy deserialization framework for Rust
- **image**: Imaging library. Provides basic image processing and encoders/decoders for common image formats.
