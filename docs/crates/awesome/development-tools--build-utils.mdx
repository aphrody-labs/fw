## About each crate

- **cc**: A build-time dependency for Cargo build scripts to assist in invoking the native C compiler to compile native C code into a static archive to be linked into Rust code. 
- **inventory**: Typed distributed plugin registration
- **ctor**: Global, no\_std-compatible constructors for all platforms that run before main (like C/C++ \_\_attribute\_\_((constructor)))
- **tonic-prost-build**: Prost build integration for tonic
- **cmake**: A build dependency for running \`cmake\` to build a native library 
- **vergen**: Generate 'cargo:rustc-env' instructions via 'build.rs' for use in your code via the 'env!' macro
- **cxx-build**: C++ code generator for integrating \`cxx\` crate into a Cargo build.
- **linkme**: Safe cross-platform linker shenanigans
- **rustversion**: Conditional compilation according to rustc compiler version
- **find-msvc-tools**: Find windows-specific tools, read MSVC versions from the registry and from COM interfaces
- **vergen-gitcl**: Generate 'cargo:rustc-env' instructions via 'build.rs' for use in your code via the 'env!' macro
- **protox**: A rust implementation of the protobuf compiler.
- **litrs**: Parse and inspect Rust literals (i.e. tokens in the Rust programming language representing fixed values). Particularly useful for proc macros, but can also be used outside of a proc-macro context. 
- **autocfg**: Automatic cfg for Rust compiler features
- **dtor**: Global, no\_std-compatible destructors for all platforms that run after main (like C/C++ \_\_attribute\_\_((destructor)))
- **vergen-gix**: Generate 'cargo:rustc-env' instructions via 'build.rs' for use in your code via the 'env!' macro
- **embuild**: A build support library for embedded Rust
- **vergen-git2**: Generate 'cargo:rustc-env' instructions via 'build.rs' for use in your code via the 'env!' macro
- **cfg\_aliases**: A tiny utility to help save you a lot of effort with long winded \`#\[cfg()\]\` checks.
- **msvc\_spectre\_libs**: Link against the Spectre-mitigated CRT import libraries for Windows MSVC targets; a no-op on every other target.
- **ts-rs**: generate typescript bindings from rust types
- **vergen-lib**: Common code used to support the vergen libraries
- **slint-build**: Compile .slint UI files to Rust code from a Cargo build script
- **connectrpc-build**: Build-time integration for connectrpc (use in build.rs)
- **link-section**: Link-time initialized slices for Rust, with full support for Linux, macOS, Windows, WASM and many more platforms.
