## About each crate

- **noodles**: Bioinformatics I/O libraries
- **noodles-csi**: Coordinate-sorted index (CSI) format reader and writer
- **noodles-sam**: Sequence Alignment/Map (SAM) format reader and writer
- **noodles-vcf**: Variant Call Format (VCF) reader and writer
- **noodles-bam**: Binary Alignment/Map (BAM) format reader and writer
- **noodles-core**: Shared utilities when working with noodles
- **noodles-tabix**: Tabix (TBI) format reader and writer
- **noodles-fasta**: FASTA format reader and writer
- **bio**: A bioinformatics library for Rust. This library provides implementations of many algorithms and data structures that are useful for bioinformatics, but also in other fields.
- **noodles-gff**: Generic Feature Format (GFF) reader and writer
- **noodles-cram**: CRAM format reader and writer
- **noodles-bcf**: Binary Call Format (BCF) reader and writer
- **noodles-util**: noodles support utilities
- **noodles-gtf**: Gene Transfer Format (GTF) reader and writer
- **noodles-bed**: BED (Browser Extensible Data) reader and writer
- **noodles-fastq**: FASTQ format reader and writer
- **bitnuc**: A library for efficient nucleotide sequence manipulation using 2-bit encoding
- **packed-seq**: Constructing and iterating packed DNA sequences using SIMD
- **simd-minimizers**: A SIMD-accelerated library to compute random minimizers
- **binseq**: A high efficiency binary format for sequencing data
- **ann-search-rs**: Various vector search algorithms in Rust. Designed specifically for single cell & computational biology applications.
- **immunum**: Fast antibody and T-cell receptor numbering in Rust and Python
- **bio-seq**: Bit packed and well-typed biological sequences
- **brust-seq**: Sequence and quality primitives for Brust: IUPAC reverse complement and matching, codon translation, and Phred means.
- **bio\_apis**: Interact with biology and chemistry databases and APIs
