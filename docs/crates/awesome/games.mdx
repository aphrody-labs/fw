## About each crate

- **shakmaty**: Chess and chess variant rules and operations
- **steamworks**: Provides rust friendly bindings to the steamworks sdk
- **tobj**: A lightweight OBJ loader in the spirit of tinyobjloader
- **bevy\_skein**: Process glTF extras when spawning Scenes to insert Components using Reflection, such as when using Blender as an editor
- **leafwing-input-manager**: A powerful, flexible and ergonomic way to manage action-input keybindings for the Bevy game engine.
- **bevy\_flair\_core**: Bevy UI styling using CSS
- **pgn-reader**: Fast non-allocating and streaming reader for chess games in PGN notation
- **bevy\_flair**: Bevy UI styling using CSS
- **bevy\_flair\_style**: Bevy UI styling using CSS
- **bevy\_flair\_css\_parser**: Bevy UI styling using CSS
- **portablemc**: Developer-oriented crate for launching Minecraft quickly and reliably with included support for Mojang versions and popular mod loaders. See portablemc-cli for the reference implementation.
- **pkcore**: Prototype core poker library.
- **rsshogi**: Reusable Rust shogi primitives for board state, move generation, legality, and record parsing.
- **nom-mpq**: A nom parser for the MoPaQ archive format
- **gatelogue-types**: Types for loading and reading Gatelogue data
- **little-sorry**: Library to help with coding regret minimization.
- **map\_3d**: Library for 3D geographic coordinate transformation
- **bevy\_fluent**: Bevy plugin for localization using Fluent
- **rumenx-sudoku**: Fast Sudoku generator & solver — classic 9×9 plus configurable grids — with unique puzzles, CLI, and REST server.
- **shakmaty-syzygy**: Probe Syzygy endgame tablebases
- **gigachess**: The fastest chess engine and move generator in Rust (100% MIT). 540M nodes/s perft, PEXT / Fancy Magic bitboards, 16-bit binary replay, Shakmaty drop-in compat.
- **s2protocol**: A parser for Starcraft II - Replay format, exports to different target formats
- **bevy\_vrm1**: Allows you to use VRM and VRMA in Bevy
- **libloadorder**: A cross-platform library for manipulating the load order and active status of plugins for the Elder Scrolls and Fallout games.
- **rs\_poker**: A library to help with any Rust code dealing with poker. This includes card values, suits, hands, hand ranks, 5 card hand strength calculation, 7 card hand strength calulcation, and monte carlo game simulation helpers.
