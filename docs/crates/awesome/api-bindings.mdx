## About each crate

- **flate2**: DEFLATE compression and decompression exposed as Read/BufRead/Write streams. Supports miniz\_oxide and multiple zlib implementations. Supports zlib, gzip, and raw deflate streams. 
- **pyo3**: Bindings to Python interpreter
- **zstd**: Binding for the zstd compression library.
- **tree-sitter**: Rust bindings to the Tree-sitter parsing library
- **openssl**: OpenSSL bindings
- **socket2**: Utilities for handling networking sockets with a maximal amount of configuration possible intended. 
- **opentelemetry**: OpenTelemetry API for Rust
- **kube**: Kubernetes client and async controller runtime
- **objc2**: Objective-C interface and runtime bindings
- **tree-sitter-language**: The tree-sitter Language type, used by the library and by language implementations
- **libloading**: Bindings around the platform's dynamic library loading primitives with greatly improved memory safety.
- **numpy**: PyO3-based Rust bindings of the NumPy C-API
- **azure\_core**: Rust wrappers around Microsoft Azure REST APIs - Core crate
- **pyo3-build-config**: Build configuration for the PyO3 ecosystem
- **async-nats**: A async Rust NATS client
- **wayland-client**: Bindings to the standard C implementation of the wayland protocol, client side.
- **cxx**: Safe interop between Rust and C++
- **gloo-timers**: Convenience crate for working with JavaScript timers
- **zstd-sys**: Low-level bindings for the zstd compression library.
- **zstd-safe**: Safe low-level bindings for the zstd compression library.
- **landlock**: Safe abstraction for Linux Landlock sandboxing
- **gstreamer**: Rust bindings for GStreamer
- **jni**: Rust bindings to the JNI
- **gtk4**: Rust bindings of the GTK 4 library
- **wayland-backend**: Low-level bindings to the Wayland protocol
