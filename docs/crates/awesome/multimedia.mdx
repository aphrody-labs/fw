## About each crate

- **gstreamer**: Rust bindings for GStreamer
- **symphonia**: Pure Rust media container and audio decoding library.
- **gstreamer-video**: Rust bindings for GStreamer Video library
- **gstreamer-base**: Rust bindings for GStreamer Base library
- **sdl2**: SDL2 bindings for Rust
- **id3**: A library for reading and writing ID3 metadata
- **opencv**: Rust bindings for OpenCV
- **lofty**: Audio metadata library
- **gstreamer-sys**: FFI bindings to libgstreamer-1.0
- **exr**: Read and write OpenEXR files without any unsafe code
- **gstreamer-audio**: Rust bindings for GStreamer Audio library
- **str0m**: WebRTC library in Sans-IO style
- **gstreamer-app**: Rust bindings for GStreamer App library
- **screencapturekit**: Safe Rust bindings for Apple's ScreenCaptureKit framework - screen and audio capture on macOS
- **pipewire**: Rust bindings for PipeWire
- **ffmpeg-next**: Safe FFmpeg wrapper (FFmpeg 4 compatible fork of the ffmpeg crate)
- **gstreamer-base-sys**: FFI bindings to libgstbase-1.0
- **symphonia-core**: Project Symphonia shared structs, traits, and features.
- **krilla**: A high-level crate for creating PDF files.
- **oxideav-core**: Core types and registries for oxideav — timestamps, packets, frames, codec/container/source/filter registries (pure Rust, no C deps)
- **softbuffer**: Cross-platform software buffer
- **gstreamer-video-sys**: FFI bindings to libgstvideo-1.0
- **ffmpeg-sidecar**: Wrap a standalone FFmpeg binary in an intuitive Iterator interface.
- **gstreamer-pbutils**: Rust bindings for GStreamer Base Utils library
- **sdl3-sys**: Low level Rust bindings for SDL 3
