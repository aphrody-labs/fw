## About each crate

- **pyo3**: Bindings to Python interpreter
- **bindgen**: Automatically generates Rust FFI bindings to C and C++ libraries.
- **objc2**: Objective-C interface and runtime bindings
- **tree-sitter-language**: The tree-sitter Language type, used by the library and by language implementations
- **numpy**: PyO3-based Rust bindings of the NumPy C-API
- **pyo3-build-config**: Build configuration for the PyO3 ecosystem
- **cxx**: Safe interop between Rust and C++
- **cxx-build**: C++ code generator for integrating \`cxx\` crate into a Cargo build.
- **pyo3-async-runtimes**: PyO3 bridges from Rust runtimes to Python's Asyncio library
- **pyo3-ffi**: Python-API bindings for the PyO3 ecosystem
- **sqlite-wasm-rs**: \`wasm32-unknown-unknown\` bindings to the libsqlite3 library.
- **ic-cdk**: Canister Developer Kit for the Internet Computer.
- **dispatch2**: Bindings and wrappers for Apple's Grand Central Dispatch (GCD)
- **pyo3-macros**: Proc macros for PyO3 package
- **cbindgen**: A tool for generating C bindings to Rust code.
- **magnus**: High level Ruby bindings. Write Ruby extension gems in Rust, or call Ruby code from a Rust binary.
- **hdf5-metno-sys**: Native bindings to the HDF5 library.
- **objc2-foundation**: Bindings to the Foundation framework
- **pyo3-macros-backend**: Code generation for PyO3 package
- **ts-rs**: generate typescript bindings from rust types
- **libffi**: Rust bindings for libffi
- **block2**: Apple's C language extension of blocks
- **os\_str\_bytes**: Lossless functionality for platform-native strings 
- **cpp\_build**: Cargo build script for the \`cpp\` crate
- **objc2-app-kit**: Bindings to the AppKit framework
