## About each crate

- **argon2**: Pure Rust implementation of the Argon2 password hashing function with support for the Argon2d, Argon2i, and Argon2id algorithmic variants 
- **pbkdf2**: Generic implementation of PBKDF2
- **ssh-key**: Pure Rust implementation of SSH key file format decoders/encoders as described in RFC4251/RFC4253 and OpenSSH key formats, as well as "sshsig" signatures and certificates (including certificate validation and certificate authority support), with further support for the \`authorized\_keys\` and \`known\_hosts\` file formats. 
- **scrypt**: Scrypt password-based key derivation function
- **ssh-encoding**: Pure Rust implementation of SSH data type decoders/encoders as described in RFC4251
- **password-hash**: Traits which describe the functionality of password hashing algorithms, with optional support for a \`no\_std\`/\`no\_alloc\`-friendly implementation of the PHC string format, as well as generic support for other formats (e.g. Modular Crypt Format) 
- **webauthn-rs**: Webauthn Framework for Rust Web Servers
- **reqsign**: Signing HTTP requests for AWS, Azure, Google, Huawei, Aliyun, Tencent and Oracle services
- **totp-rs**: RFC-compliant TOTP implementation with ease of use as a goal and additional QoL features.
- **spiffe**: Core SPIFFE identity types, Workload API sources, and experimental Broker API bindings
- **gcp\_auth**: Google cloud platform (GCP) authentication using default and custom service accounts
- **webauthn-rs-proto**: Webauthn Specification Bindings
- **sequoia-openpgp**: OpenPGP data types and associated machinery
- **webauthn-rs-core**: Webauthn Cryptographic Operation Handling
- **password-auth**: Password authentication library with a focus on simplicity and ease-of-use, including support for Argon2, PBKDF2, and scrypt password hashing algorithms 
- **coins-ledger**: Ledger Nano X/S connection and communication management library
- **bcrypt-pbkdf**: bcrypt-pbkdf password-based key derivation function
- **pubky**: Pubky SDK
- **pasetors**: PASETO: Platform-Agnostic Security Tokens (in Rust)
- **openid**: OpenID Connect & Discovery client library using async / await. 
- **cf-gears-toolkit-security**: ToolKit security library
- **didwebvh-rs**: Implementation of the did:webvh method in Rust
- **yubikey**: Pure Rust cross-platform host-side driver for YubiKey devices from Yubico with support for hardware-backed public-key decryption and digital signatures using the Personal Identity Verification (PIV) application. Supports RSA (1024/2048/3072/4096) or ECC (NIST P-256/P-384) algorithms e.g, PKCS#1v1.5, ECDSA 
- **zkryptium**: Rust crypto library for zero-knowledge proofs
- **hyper-http-proxy**: A proxy connector for Hyper-based applications
