## About each crate

- **zip**: Library to support the reading and writing of zip files.
- **notify**: Cross-platform filesystem notification library
- **rustix**: Safe Rust bindings to POSIX/Unix/Linux/Winsock-like syscalls
- **which**: A Rust equivalent of Unix command "which". Locate installed executable in cross platforms.
- **camino**: UTF-8 paths
- **rust-embed**: Rust Custom Derive Macro which loads files into the rust binary at compile time during release and loads the file from the fs during dev
- **glob**: Support for matching file paths against Unix shell style patterns. 
- **io-uring**: The low-level \`io\_uring\` userspace interface for Rust
- **bytesize**: Semantic wrapper for byte count representations
- **opendal**: Apache OpenDAL™: One Layer, All Storage.
- **landlock**: Safe abstraction for Linux Landlock sandboxing
- **typed-path**: Provides typed variants of Path and PathBuf for Unix and Windows
- **inotify**: Idiomatic wrapper for inotify
- **fs4**: No libc, pure Rust cross-platform file locks. Original fs2, now supports async and replace libc by rustix.
- **fs-err**: A drop-in replacement for std::fs with more helpful error messages.
- **relative-path**: Portable, relative paths for Rust.
- **notify-types**: Types used by the notify crate
- **opendal-core**: Apache OpenDAL™: One Layer, All Storage.
- **fuser**: Filesystem in Userspace (FUSE) for Rust
- **cap-std**: Capability-based version of the Rust standard library
- **exr**: Read and write OpenEXR files without any unsafe code
- **hdf5-metno**: Thread-safe Rust bindings for the HDF5 library.
- **normpath**: More reliable path manipulation 
- **reflink-copy**: copy-on-write mechanism on supported file systems
- **cap-fs-ext**: Extension traits for \`Dir\`, \`File\`, etc.
