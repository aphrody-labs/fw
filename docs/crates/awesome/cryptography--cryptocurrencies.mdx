## About each crate

- **alloy-primitives**: Ethereum primitive types
- **k256**: secp256k1 elliptic curve library written in pure Rust with support for ECDSA signing/verification/public-key recovery, Taproot Schnorr signatures (BIP340), Elliptic Curve Diffie-Hellman (ECDH), and general-purpose secp256k1 elliptic curve group operations which can be used to implement arbitrary protocols 
- **alloy-sol-types**: Compile-time ABI and EIP-712 implementations
- **bitcoin**: General purpose library for using and interoperating with Bitcoin.
- **alloy-rlp**: Implementation of Ethereum RLP serialization
- **bech32**: Encodes and decodes the Bech32 format and implements the bech32 and bech32m checksums
- **alloy-json-abi**: Full Ethereum JSON-ABI implementation
- **alloy-dyn-abi**: Run-time ABI and EIP-712 implementations
- **alloy-core**: Rust Ethereum core libraries
- **alloy-chains**: Canonical type definitions for EIP-155 chains
- **bitcoin-internals**: Internal types and macros used by rust-bitcoin ecosystem
- **alloy-sol-macro**: Solidity to Rust procedural macro
- **zcash\_primitives**: Rust implementations of the Zcash primitives
- **bitcoin-units**: Basic Bitcoin numeric units such as amount
- **zcash\_protocol**: Zcash protocol network constants and value types.
- **bitcoin-consensus-encoding**: Consensus encoding and decoding
- **coins-bip32**: Bip32 in Rust
- **orchard**: The Orchard shielded transaction protocol
- **syn-solidity**: syn-powered Solidity parser
- **zcash\_address**: Zcash address parsing and serialization
- **zcash\_keys**: Zcash key and address management
- **coins-bip39**: BIP39 implementation for coins
- **p3-field**: A modular framework for finite fields, including support for generic binomial extensions, SIMD-packed field arithmetic.
- **zcash\_encoding**: Binary encodings used throughout the Zcash ecosystem.
- **base58ck**: Bitcoin base58 encoding with checksum.
