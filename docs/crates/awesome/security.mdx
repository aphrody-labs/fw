## About each crate

- **keepass**: KeePass .kdbx database file parser
- **dimpl**: DTLS 1.2/1.3 implementation (Sans‑IO, Sync)
- **pam-bindings**: Simplified PAM module creation in Rust
- **bhttp**: Binary HTTP messages (RFC 9292)
- **ohttp**: Oblivious HTTP
- **path\_jail**: A secure filesystem sandbox. Restricts paths to a root directory, preventing traversal attacks.
- **cvss-rs**: A Rust library for representing and deserializing CVSS (Common Vulnerability Scoring System) data.
- **cf-gears-credstore-sdk**: SDK for credstore gear: API traits, models, and error definitions
- **cf-gears-credstore**: credstore gear module
- **secretscan**: A blazing-fast secret scanner for your codebase
- **towershield-core**: Portable rules and matchers for blocking common vulnerability-scanner paths.
- **affidavit**: Provenance Layer — receipt assembly and certification, with an optional crypto trust plane (signatures, post-quantum, key custody). Verify a witness against a format standard; never decide honesty.
- **ambient-id**: Detects ambient OIDC credentials in a variety of environments
- **idalib-build**: Idiomatic bindings to IDA SDK
- **threatflux-string-analysis**: Deterministic, configurable string analysis primitives for security tooling
- **idalib**: Idiomatic bindings to IDA SDK
- **actix-web-ratelimit**: A simple and highly customizable rate limiter for actix-web 4
- **dinvk**: Dynamically invoke arbitrary code in Rust
- **zizmor**: Static analysis for GitHub Actions
- **secure-types**: Secure data types that protect sensitive data in memory via locking and zeroization.
- **hardened-malloc-sys**: Rust bindings for GrapheneOS allocator
- **hardened-malloc**: Global allocator using GrapheneOS allocator
- **sbom-tools**: Semantic SBOM diff and analysis tool
- **idalib-sys**: Idiomatic bindings to IDA SDK
- **towershield**: Tower middleware that blocks common vulnerability-scanner paths before they reach your application.
