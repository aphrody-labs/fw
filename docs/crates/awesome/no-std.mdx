## About each crate

- **serde\_json**: A JSON serialization file format
- **rand**: Random number generators and other randomness functionality. 
- **thiserror**: derive(Error)
- **sha2**: Pure Rust implementation of the SHA-2 hash function family including SHA-224, SHA-256, SHA-384, and SHA-512. 
- **uuid**: A library to generate and parse UUIDs.
- **libc**: Raw FFI bindings to platform libraries like libc.
- **anyhow**: Flexible concrete Error type built on std::error::Error
- **url**: URL library for Rust, based on the WHATWG URL Standard
- **serde**: A generic serialization/deserialization framework
- **indexmap**: A hash table with consistent order and fast iteration.
- **zeroize**: Securely clear secrets from memory with a simple trait built on stable Rust primitives which guarantee memory is zeroed using an operation will not be 'optimized away' by the compiler. Uses a portable pure Rust implementation that works everywhere, even WASM, with \`asm!\` optimizations on select platforms 
- **schemars**: Generate JSON Schemas from Rust code
- **bitflags**: A macro to generate structures which behave like bitflags. 
- **getrandom**: A small cross-platform library for retrieving random data from system source
- **rand\_core**: Core random number generator traits and tools for implementation. 
- **either**: The enum \`Either\` with variants \`Left\` and \`Right\` is a general purpose sum type with two cases. 
- **serde\_with**: Custom de/serialization functions for Rust's serde
- **time**: Date and time library. Fully interoperable with the standard library. Mostly compatible with #!\[no\_std\].
- **async-trait**: Type erasure for async trait methods
- **ordered-float**: Wrappers for total ordering on floats
- **aes**: Pure Rust implementation of the Advanced Encryption Standard (a.k.a. Rijndael)
- **jiff**: A date-time library that encourages you to jump into the pit of success.  This library is heavily inspired by the Temporal project. 
- **crc32fast**: Fast, SIMD-accelerated CRC32 (IEEE) checksum computation
- **sha1**: SHA-1 hash function
- **defmt**: A highly efficient logging framework that targets resource-constrained devices, like microcontrollers
