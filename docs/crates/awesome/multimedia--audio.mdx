## About each crate

- **cpal**: Low-level cross-platform audio I/O library.
- **rubato**: Asynchronous resampling library intended for audio data
- **symphonia**: Pure Rust media container and audio decoding library.
- **id3**: A library for reading and writing ID3 metadata
- **lofty**: Audio metadata library
- **symphonia-core**: Project Symphonia shared structs, traits, and features.
- **audioadapter-buffers**: A selection of wrappers and buffers for audio data
- **audioadapter**: A library for making it easier to work with buffers of audio data
- **symphonia-metadata**: Project Symphonia multimedia tag and metadata readers.
- **alsa**: Thin but safe wrappers for ALSA (Linux sound API)
- **alsa-sys**: FFI bindings for the ALSA project (Advanced Linux Sound Architecture)
- **wasapi**: Bindings for the Wasapi API on Windows
- **mp3lame-encoder**: High level bindings to mp3lame encoder
- **symphonia-codec-aac**: Pure Rust AAC decoder (a part of project Symphonia).
- **sonora**: WebRTC Audio Processing — pure Rust port with echo cancellation, noise suppression, and AGC
- **kira**: Expressive audio library for games
- **audioadapter-sample**: A library for making it easier to work with audio data
- **midir**: A cross-platform, realtime MIDI processing library, inspired by RtMidi.
- **symphonia-bundle-mp3**: Pure Rust MP1, MP2, and MP3 demuxer and decoder (a part of project Symphonia).
- **symphonia-codec-vorbis**: Pure Rust Vorbis decoder (a part of project Symphonia).
- **bevy\_kira\_audio**: Bevy plugin for dynamic audio
- **symphonia-format-ogg**: Pure Rust OGG demuxer (a part of project Symphonia).
- **ogg\_pager**: A simple OGG page reader
- **audio-codec-algorithms**: Audio codec algorithms: A-law, μ-law and IMA ADPCM
- **symphonia-common**: Project Symphonia utilities for codecs and formats.
