## About each crate

- **serde**: A generic serialization/deserialization framework
- **serde\_with**: Custom de/serialization functions for Rust's serde
- **zerocopy**: Zerocopy makes zero-cost memory manipulation effortless. We write "unsafe" so you don't have to.
- **pin-project**: A crate for safe and ergonomic pin-projection. 
- **itoa**: Fast integer primitive to string conversion
- **unicode-width**: Determine displayed width of \`char\` and \`str\` types according to Unicode Standard Annex #11 rules. 
- **itertools**: Extra iterator adaptors, iterator methods, free functions, and macros.
- **pin-project-lite**: A lightweight version of pin-project written with declarative macros. 
- **serde\_derive**: Macros 1.1 implementation of #\[derive(Serialize, Deserialize)\]
- **bon**: Next-gen compile-time-checked builder generator, named function's arguments, and more!
- **inventory**: Typed distributed plugin registration
- **unicode-ident**: Determine whether characters have the XID\_Start or XID\_Continue properties according to Unicode Standard Annex #31
- **ctor**: Global, no\_std-compatible constructors for all platforms that run before main (like C/C++ \_\_attribute\_\_((constructor)))
- **portable-atomic**: Portable atomic types including support for 128-bit atomics, atomic float, etc. 
- **rkyv**: Zero-copy deserialization framework for Rust
- **owo-colors**: Zero-allocation terminal colors that'll make people go owo
- **xxhash-rust**: Implementation of xxhash
- **linkme**: Safe cross-platform linker shenanigans
- **indoc**: Indented document literals
- **csscolorparser**: Zero-allocation CSS color parser library. Supports absolute and relative color formats.
- **serde\_repr**: Derive Serialize and Deserialize that delegates to the underlying repr of a C-like enum.
- **zmij**: A double-to-string conversion algorithm based on Schubfach and xjb
- **ryu**: Fast floating point to string conversion
- **rustversion**: Conditional compilation according to rustc compiler version
- **ref-cast**: Safely cast &T to &U where the struct U contains a single field of type T.
