## About each crate

- **objc2**: Objective-C interface and runtime bindings
- **security-framework**: Security.framework bindings for macOS and iOS
- **system-configuration**: Bindings to SystemConfiguration framework for macOS
- **dispatch2**: Bindings and wrappers for Apple's Grand Central Dispatch (GCD)
- **doom-fish-utils**: Framework-agnostic FFI utilities shared by the doom-fish Apple-SDK Rust bindings: async/sync completion handlers, FFI string helpers, FourCharCode, panic-safe extern-C wrappers, and executor-agnostic bounded async streams.
- **screencapturekit**: Safe Rust bindings for Apple's ScreenCaptureKit framework - screen and audio capture on macOS
- **objc2-foundation**: Bindings to the Foundation framework
- **apple-cf**: Safe Rust bindings for Apple's shared Core\* frameworks (CoreFoundation, CoreMedia, CoreVideo, CoreGraphics, IOSurface, Dispatch).
- **security-framework-sys**: Apple \`Security.framework\` low-level FFI bindings
- **core-foundation**: Bindings to Core Foundation for macOS
- **block2**: Apple's C language extension of blocks
- **objc2-app-kit**: Bindings to the AppKit framework
- **objc2-core-foundation**: Bindings to the CoreFoundation framework
- **apple-metal**: Safe Rust bindings for Apple's Metal framework — devices, resources, command encoding, advanced GPU objects, and IOSurface interop on macOS, backed by a Swift bridge
- **objc2-core-graphics**: Bindings to the CoreGraphics framework
- **objc2-metal**: Bindings to the Metal framework
- **objc2-quartz-core**: Bindings to the QuartzCore/CoreAnimation framework
- **objc2-ui-kit**: Bindings to the UIKit framework
- **objc2-io-surface**: Bindings to the IOSurface framework
- **objc2-user-notifications**: Bindings to the UserNotifications framework
- **objc2-core-video**: Bindings to the CoreVideo framework
- **objc2-core-text**: Bindings to the CoreText framework
- **core-video**: Safe bindings to CoreVideo framework
- **objc2-io-kit**: Bindings to the IOKit framework
- **objc2-web-kit**: Bindings to the WebKit framework
