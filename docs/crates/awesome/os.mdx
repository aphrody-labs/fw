## About each crate

- **libc**: Raw FFI bindings to platform libraries like libc.
- **zeroize**: Securely clear secrets from memory with a simple trait built on stable Rust primitives which guarantee memory is zeroed using an operation will not be 'optimized away' by the compiler. Uses a portable pure Rust implementation that works everywhere, even WASM, with \`asm!\` optimizations on select platforms 
- **getrandom**: A small cross-platform library for retrieving random data from system source
- **which**: A Rust equivalent of Unix command "which". Locate installed executable in cross platforms.
- **camino**: UTF-8 paths
- **ctrlc**: Easy Ctrl-C handler for Rust projects
- **whoami**: Rust library for getting information about the current user and environment
- **errno**: Cross-platform interface to the \`errno\` variable.
- **interprocess**: Interprocess communication toolkit
- **r-efi**: UEFI Reference Specification Protocol Constants and Definitions
- **typed-path**: Provides typed variants of Path and PathBuf for Unix and Windows
- **fontique**: Font enumeration and fallback.
- **opener**: Open a file or link using the system default program.
- **serial2**: Cross platform serial ports
- **oo7**: James Bond went on a new mission and this time as a Secret Service provider
- **region**: Cross-platform virtual memory API
- **hostname**: Cross-platform system's host name functions
- **normpath**: More reliable path manipulation 
- **os\_info**: Detect the operating system type and version.
- **reflink-copy**: copy-on-write mechanism on supported file systems
- **zeroize\_derive**: Custom derive support for zeroize
- **iana-time-zone**: get the IANA time zone for the current system
- **wl-clipboard-rs**: Access to the Wayland clipboard for terminal and other window-less applications.
- **platform-info**: A simple cross-platform interface to get info about a system
- **sev**: Library for AMD SEV
