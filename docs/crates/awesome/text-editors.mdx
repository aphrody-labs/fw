## About each crate

- **tree-sitter**: Rust bindings to the Tree-sitter parsing library
- **tree-sitter-highlight**: Library for performing syntax highlighting with Tree-sitter
- **ratatui-textarea**: ratatui-textarea is a simple yet powerful text editor widget for ratatui. Multi-line text editor can be easily put as part of your TUI application. 
- **tree-sitter-scala**: Scala grammar for tree-sitter
- **tree-sitter-c-sharp**: C# grammar for tree-sitter
- **tree-sitter-tags**: Library for extracting tag information
- **tree-sitter-php**: PHP grammar for tree-sitter
- **tree-sitter-swift**: swift grammar for the tree-sitter parsing library
- **tree-sitter-powershell**: A Powershell grammar for tree-sitter
- **tree-sitter-md**: Markdown grammar for tree-sitter
- **tree-sitter-rust**: Rust grammar for tree-sitter
- **tree-sitter-graphql**: GraphQL grammar for tree-sitter
- **tui-textarea-2**: tui-textarea is a simple yet powerful text editor widget for ratatui. Multi-line text editor can be easily put as part of your TUI application. 
- **tree-sitter-dart**: Dart grammar for tree-sitter
- **tree-sitter-erlang**: erlang grammar for the tree-sitter parsing library
- **tree-sitter-proto**: Parser for proto2 and proto3 files
- **tree-sitter-cmake**: CMake grammar for tree-sitter
- **tree-sitter-sequel**: Tree-sitter Grammar for SQL
- **tree-sitter-c**: C grammar for tree-sitter
- **tree-sitter-ocaml**: OCaml grammar for tree-sitter
- **tree-sitter-fsharp**: fsharp grammar for the tree-sitter parsing library
- **tree-sitter-bash**: Bash grammar for tree-sitter
- **arborium-tree-sitter**: Rust bindings to the Tree-sitter parsing library (vendored for arborium WASM support)
- **tree-sitter-haskell**: Haskell grammar for tree-sitter
- **tree-sitter-lua**: Lua grammar for tree-sitter
