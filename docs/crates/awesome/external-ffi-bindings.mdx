## About each crate

- **libc**: Raw FFI bindings to platform libraries like libc.
- **tree-sitter**: Rust bindings to the Tree-sitter parsing library
- **openssl-sys**: FFI bindings to OpenSSL
- **bindgen**: Automatically generates Rust FFI bindings to C and C++ libraries.
- **objc2**: Objective-C interface and runtime bindings
- **libsqlite3-sys**: Native bindings to the libsqlite3 library
- **fs4**: No libc, pure Rust cross-platform file locks. Original fs2, now supports async and replace libc by rustix.
- **fuser**: Filesystem in Userspace (FUSE) for Rust
- **libz-sys**: Low-level bindings to the system libz library (also known as zlib).
- **opencv**: Rust bindings for OpenCV
- **cryptoki**: Rust-native wrapper around the PKCS #11 API
- **tss-esapi**: Rust-native wrapper around TSS 2.0 Enhanced System API
- **llvm-sys**: Bindings to LLVM's C API
- **libduckdb-sys**: Native bindings to the libduckdb library, C API
- **boring-sys**: FFI bindings to BoringSSL
- **dispatch2**: Bindings and wrappers for Apple's Grand Central Dispatch (GCD)
- **cbindgen**: A tool for generating C bindings to Rust code.
- **z3-sys**: Low-level bindings for the Z3 SMT solver from Microsoft Research
- **objc2-foundation**: Bindings to the Foundation framework
- **wayland-sys**: FFI bindings to the various libwayland-\*.so libraries. You should only need this crate if you are working on custom wayland protocol extensions. Look at the crate wayland-client for usable bindings.
- **cubecl-hip-sys**: Rust bindings for AMD ROCm HIP runtime libraries used by CubeCL.
- **security-framework-sys**: Apple \`Security.framework\` low-level FFI bindings
- **block2**: Apple's C language extension of blocks
- **liblzma-sys**: Raw bindings to liblzma which contains an implementation of LZMA and xz stream encoding/decoding.  High level Rust bindings are available in the \`liblzma\` crate. 
- **jni-sys**: Rust definitions corresponding to jni.h
