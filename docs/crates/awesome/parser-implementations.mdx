## About each crate

- **serde\_json**: A JSON serialization file format
- **syn**: Parser for Rust source code
- **toml**: A native Rust encoder and decoder of TOML-formatted files and streams. Provides implementations of the standard Serialize/Deserialize traits for TOML data to facilitate deserializing and serializing Rust structures. 
- **uuid**: A library to generate and parse UUIDs.
- **url**: URL library for Rust, based on the WHATWG URL Standard
- **toml\_edit**: Yet another format-preserving TOML parser.
- **zip**: Library to support the reading and writing of zip files.
- **quick-xml**: High performance xml reader and writer
- **time**: Date and time library. Fully interoperable with the standard library. Mostly compatible with #!\[no\_std\].
- **der**: Pure Rust embedded-friendly implementation of the Distinguished Encoding Rules (DER) for Abstract Syntax Notation One (ASN.1) as described in ITU X.690 with full support for heapless \`no\_std\`/\`no\_alloc\` targets 
- **html5ever**: High-performance browser-grade HTML5 parser
- **plist**: A rusty plist parser. Supports Serde serialization.
- **rhai**: Embedded scripting for Rust
- **serde-saphyr**: YAML (de)serializer for Serde, emphasizing panic-free parsing, fast builds and good error reporting. Supports properties, include, tag and comment capture
- **pkcs8**: Pure Rust implementation of Public-Key Cryptography Standards (PKCS) #8: Private-Key Information Syntax Specification (RFC 5208), with additional support for PKCS#8v2 asymmetric key packages (RFC 5958) 
- **const-oid**: Const-friendly implementation of the ISO/IEC Object Identifier (OID) standard as defined in ITU X.660, with support for BER/DER encoding/decoding as well as no\_std + no\_alloc (i.e. embedded) support 
- **toml\_datetime**: A TOML-compatible datetime type
- **ssh-key**: Pure Rust implementation of SSH key file format decoders/encoders as described in RFC4251/RFC4253 and OpenSSH key formats, as well as "sshsig" signatures and certificates (including certificate validation and certificate authority support), with further support for the \`authorized\_keys\` and \`known\_hosts\` file formats. 
- **shlex**: Split a string into shell words, like Python's shlex.
- **roxmltree**: Represent an XML as a read-only tree.
- **markup5ever**: Common code for xml5ever and html5ever
- **serde\_spanned**: Serde-compatible spanned Value
- **saphyr-parser**: A fully YAML 1.2 compliant YAML library
- **csscolorparser**: Zero-allocation CSS color parser library. Supports absolute and relative color formats.
- **cms**: Pure Rust implementation of the Cryptographic Message Syntax (CMS) as described in RFC 5652 and RFC 3274.
