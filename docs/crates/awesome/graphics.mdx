## About each crate

- **skrifa**: Metadata reader and glyph scaler for OpenType fonts.
- **bevy**: A refreshingly simple data-driven game engine and app framework
- **read-fonts**: Reading OpenType font files.
- **parley**: Parley provides an API for implementing rich text layout.
- **csscolorparser**: Zero-allocation CSS color parser library. Supports absolute and relative color formats.
- **write-fonts**: Writing font files.
- **rgb**: \`struct RGB/RGBA/etc.\` for sharing pixels between crates + convenience methods for color manipulation. Allows no-copy high-level interoperability. Also adds common convenience methods and implements standard Rust traits to make \`RGB\`/\`RGBA\` pixels and slices first-class Rust objects.
- **vello\_cpu**: A CPU-based renderer for Vello, optimized for SIMD and multithreaded execution.
- **kurbo**: A 2D curves library
- **vello\_common**: Core data structures and utilities shared across the Vello rendering, including geometry processing and tiling logic.
- **epaint**: Minimal 2D graphics library for GUI work
- **vello**: A GPU compute-centric 2D renderer.
- **i\_overlay**: Boolean Operations for 2D Polygons: Supports intersection, union, difference, xor, and self-intersections for all polygon varieties.
- **skia-safe**: Safe Skia Bindings for Rust
- **palette**: Convert and manage colors with a focus on correctness, flexibility and ease of use.
- **exr**: Read and write OpenEXR files without any unsafe code
- **epaint\_default\_fonts**: Default fonts for use in epaint / egui
- **glifo**: Glifo provides APIs for efficiently rendering text.
- **kasuari**: A rust layout solver for GUIs, based on the Cassowary algorithm. A fork of the unmaintained cassowary-rs crate with improvments and bug fixes. Kasuari is the indonesian name for the cassowary bird. 
- **peniko**: Primitive types for styling vector graphics
- **femtovg**: Antialiased 2D vector drawing library
- **line-clipping**: A simple crate implementing line and polygon clipping algorithms.
- **krilla**: A high-level crate for creating PDF files.
- **swash**: Font introspection, complex text shaping and glyph rendering.
- **softbuffer**: Cross-platform software buffer
