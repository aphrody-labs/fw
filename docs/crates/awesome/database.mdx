- **mongodb**: The official MongoDB driver for Rust
- **tokio-postgres**: A native, asynchronous PostgreSQL client
- **diesel\_migrations**: Migration management for diesel
- **sea-orm-migration**: Migration utility for SeaORM
- **scylla**: Async CQL driver for Rust, optimized for ScyllaDB, fully compatible with Apache Cassandra™
- **maxminddb**: Library for reading MaxMind DB format used by GeoIP2 and GeoLite2
- **diesel-async**: An async extension for Diesel the safe, extensible ORM and Query Builder
- **sea-query**: 🔱 A dynamic query builder for MySQL, Postgres and SQLite
- **iceberg**: Apache Iceberg Rust implementation
- **postgres-types**: Conversions between Rust and Postgres values
- **rocksdb**: Rust wrapper for Facebook's RocksDB embeddable database
- **rusqlite\_migration**: Simple schema migration library for rusqlite using user\_version instead of an SQL table to maintain the current schema version.
- **pgrx**: pgrx:  A Rust framework for creating Postgres extensions
- **sqlite-wasm-rs**: \`wasm32-unknown-unknown\` bindings to the libsqlite3 library.
- **libduckdb-sys**: Native bindings to the libduckdb library, C API
- **postgres**: A native, synchronous PostgreSQL client
- **iceberg-catalog-rest**: Apache Iceberg Rust REST API
- **crates-index**: Library for retrieving and interacting with the crates.io index
- **refinery**: Powerful SQL migration toolkit for Rust
- **scylla-cql**: CQL data types and primitives, for interacting with ScyllaDB.
- **neo4rs**: Rust driver for Neo4j
