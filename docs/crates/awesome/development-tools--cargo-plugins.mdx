## About each crate

- **clap-cargo**: Re-usable CLI flags for \`cargo\` plugins
- **cargo-edit**: Cargo commands for modifying a \`Cargo.toml\` file..
- **cargo-audit**: Audit Cargo.lock for crates with security vulnerabilities
- **cargo-llvm-cov**: Cargo subcommand to easily use LLVM source-based code coverage (-C instrument-coverage). 
- **honggfuzz**: Fuzz your Rust code with Google-developed Honggfuzz ! 
- **tauri-bundler**: Wrap rust executables in OS-specific app bundles for Tauri
- **cargo-nextest**: A next-generation test runner for Rust.
- **cargo-expand**: Wrapper around rustc -Zunpretty=expanded. Shows the result of macro expansion and #\[derive\] expansion.
- **cargo-cyclonedx**: CycloneDX Software Bill of Materials (SBOM) for Rust Crates
- **cargo-pgrx**: Cargo subcommand for 'pgrx' to make Postgres extension development easy
- **cargo-deny**: Cargo plugin to help you manage large dependency graphs
- **flamegraph**: A simple cargo subcommand for generating flamegraphs, using inferno under the hood
- **nornir-testmatrix**: Reusable, multi-aspect Rust test-matrix engine: wrap a repo's native cargo test/nextest plus build/clippy/fmt/audit/coverage/doctest aspects, parse the results into rows, and ship them to any TestSink. Pure std + serde — no iceberg, arrow, eframe. The portable core of nornir's \`nornir test\` matrix.
- **cargo-about**: Cargo plugin for generating a listing of all of the crates and the the terms under which they are licensed
- **cargo-semver-checks**: Scan your Rust crate for semver violations.
- **cargo-readme**: A cargo subcommand to generate README.md content from doc comments
- **cargo-deb**: Make Debian packages (.deb) easily with a Cargo subcommand
- **cargo-release**: Cargo subcommand for you to smooth your release process.
- **cargo-sort**: Check if tables and items in a .toml file are lexically sorted
- **tracel-xtask**: Reusable and Extensible xtask commands to manage repositories.
- **tracel-xtask-macros**: Macros for tracel-xtask crate.
- **cargo-shear**: Detect and fix unused/misplaced dependencies from Cargo.toml
- **cargo-c**: Helper program to build and install c-like libraries
- **cargo-mobile2**: Rust on mobile made easy!
- **cargo-hack**: Cargo subcommand to provide various options useful for testing and continuous integration.
