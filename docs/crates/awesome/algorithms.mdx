## About each crate

- **rand**: Random number generators and other randomness functionality. 
- **rand\_core**: Core random number generator traits and tools for implementation. 
- **crc32fast**: Fast, SIMD-accelerated CRC32 (IEEE) checksum computation
- **itertools**: Extra iterator adaptors, iterator methods, free functions, and macros.
- **crossbeam-channel**: Multi-producer multi-consumer channels for message passing
- **rand\_pcg**: Selected PCG random number generators
- **fastrand**: A simple and fast random number generator
- **crypto-bigint**: Pure Rust implementation of a big integer library which has been designed from the ground-up for use in cryptographic applications. Provides constant-time, \`no\_std\`/\`no\_alloc\`-friendly implementations of modern formulas using const generics. Also includes optional support for heap-backed integers. 
- **crossbeam-utils**: Utilities for concurrent programming
- **num-bigint**: Big integer implementation for Rust
- **ort**: A safe Rust wrapper for ONNX Runtime 1.31 - Optimize and accelerate machine learning inference & training
- **rand\_xoshiro**: Xoshiro, xoroshiro and splitmix64 random number generators
- **twox-hash**: A Rust implementation of the XXHash and XXH3 algorithms
- **dashmap**: Blazing fast concurrent HashMap for Rust.
- **rstar**: An R\*-tree spatial index
- **xxhash-rust**: Implementation of xxhash
- **rand\_chacha**: ChaCha random number generator 
- **crossbeam-deque**: Concurrent work-stealing deque
- **num-integer**: Integer traits and functions
- **bitcoin\_hashes**: Hash functions used by the rust-bitcoin ecosystem
- **histogram**: A collection of histogram data structures
- **rapidhash**: An extremely fast, high quality, platform-independent hashing algorithm.
- **daachorse**: Daachorse: Double-Array Aho-Corasick
- **i\_overlay**: Boolean Operations for 2D Polygons: Supports intersection, union, difference, xor, and self-intersections for all polygon varieties.
- **siphasher**: SipHash-2-4 and SipHash-1-3 keyed hash functions in pure Rust, with 64-bit and 128-bit output and no\_std support
