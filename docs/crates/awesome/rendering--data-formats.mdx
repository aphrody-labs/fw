## About each crate

- **openusd**: Rust native USD library
- **hexasphere**: A library to evenly tile hexagons on a sphere. 
- **geozero**: Zero-Copy reading and writing of geospatial data in WKT/WKB, GeoJSON, MVT, GDAL, and other formats.
- **tobj**: A lightweight OBJ loader in the spirit of tinyobjloader
- **bevy\_gaussian\_splatting**: bevy gaussian splatting render pipeline plugin
- **oxideav-mesh3d**: Pure-Rust 3D scene + mesh typed model — Decoder/Encoder traits for STL/OBJ/glTF/FBX/USD format crates
- **chematic-depict**: 2D molecular structure depiction as SVG: ring templates, wedge/dash stereo bonds, CPK coloring, grid layout — pure-Rust, no C/C++ dependencies
- **openusd-schemas**: Typed Rust APIs for USD's standard schemas (UsdGeom, UsdShade, UsdSkel, UsdPhysics, and more), built on openusd
- **harumi**: Pure-Rust PDF — CJK font embedding (Chinese/Japanese/Korean), OCR text overlay, text extraction, HTML→PDF, page merge/split. WASM-ready, zero C deps.
- **oxideav-gltf**: Pure-Rust glTF 2.0 + .glb 3D scene codec — implements oxideav-mesh3d's Decoder/Encoder traits
- **threemf**: 3MF (3D Manufacturing Format) file format support
- **oxideav-ifc**: Pure-Rust IFC (ISO 16739 BIM) reader — clean-room STEP physical-file (ISO 10303-21) parser for .ifc building models
- **poppler-rs**: High-level (safe) bindings for poppler-glib
- **oxideav-obj**: Pure-Rust Wavefront OBJ + MTL 3D mesh codec — implements oxideav-mesh3d's Decoder/Encoder traits
- **openusd-build**: Generates Rust schema views from OpenUSD schema.usda files, for use as a build dependency
- **oxideav-fbx**: Pure-Rust FBX (Filmbox) binary decoder — implements oxideav-mesh3d's Decoder trait
- **ptex-rust**: Pure-Rust reader for Disney's Ptex per-face texture file format
- **draco-gltf**: Load and save full glTF 2.0 and 2.1 draft scenes with Draco geometry
- **pbf\_font\_tools**: Tools for working with SDF font glyphs encoded in protobuf format.
- **sdf\_glyph\_renderer**: Tools for generating SDF font glyphs from bitmap images.
- **oxideav-usdz**: Pure-Rust USDZ (Universal Scene Description, zipped) reader — implements oxideav-mesh3d's Decoder trait
- **basisu**: A bit-exact pure-Rust Basis Universal texture transcoder (.ktx2 and .basis).
- **svg**: The package provides an SVG composer and parser.
- **oxideav-stl**: Pure-Rust STL (stereolithography) ASCII + binary mesh codec — implements oxideav-mesh3d's Decoder/Encoder traits
- **spirv-tools**: Wrapper crate for SPIRV-Tools
