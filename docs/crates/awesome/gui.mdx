## About each crate

- **winit**: Cross-platform window creation library.
- **egui**: An easy-to-use immediate mode GUI that runs on both web and native
- **tauri**: Make tiny, secure apps for all desktop platforms with Tauri
- **bevy**: A refreshingly simple data-driven game engine and app framework
- **eframe**: egui framework - write GUI apps that compiles to web and/or natively
- **tauri-plugin**: Build script and runtime Tauri plugin definitions
- **taffy**: A flexible UI layout library 
- **accesskit**: UI accessibility infrastructure across platforms
- **wry**: Cross-platform WebView rendering library
- **wayland-client**: Bindings to the standard C implementation of the wayland protocol, client side.
- **parley**: Parley provides an API for implementing rich text layout.
- **tauri-build**: build time code to pair with https://crates.io/crates/tauri
- **tao**: Cross-platform window manager library.
- **egui\_extras**: Extra functionality and widgets for the egui GUI library
- **gtk4**: Rust bindings of the GTK 4 library
- **wayland-backend**: Low-level bindings to the Wayland protocol
- **tray-icon**: Create tray icons for desktop applications
- **wayland-protocols**: Generated API for the officials wayland protocol extensions
- **egui-wgpu**: Bindings for using egui natively using the wgpu library
- **egui-winit**: Bindings for using egui with winit
- **ashpd**: XDG portals wrapper in Rust using zbus
- **accesskit\_winit**: AccessKit UI accessibility infrastructure: winit adapter
- **muda**: Menu Utilities for Desktop Applications
- **tauri-utils**: Utilities for Tauri
- **fontique**: Font enumeration and fallback.
