## About each crate

- **comrak**: A 100% CommonMark-compatible GitHub Flavored Markdown parser and formatter
- **serde-saphyr**: YAML (de)serializer for Serde, emphasizing panic-free parsing, fast builds and good error reporting. Supports properties, include, tag and comment capture
- **uucore**: uutils ~ 'core' uutils code library (cross-platform)
- **self\_update**: Self updates for standalone executables
- **reqsign-core**: Signing API requests without effort.
- **ast-grep-core**: Search and Rewrite code at large scale using precise AST pattern
- **oxipng**: A lossless PNG compression optimizer
- **crossterm**: A crossplatform terminal library for manipulating terminals.
- **inferno**: Rust port of the FlameGraph performance profiling tool suite
- **tree-sitter-loader**: Locates, builds, and loads tree-sitter grammars at runtime
- **espflash**: A command-line tool for interacting with Espressif devices
- **tree-sitter-generate**: Library for generating C source code from a tree-sitter grammar
- **uu\_cp**: cp ~ (uutils) copy SOURCE to DESTINATION
- **iggy**: Iggy is the persistent message streaming platform written in Rust, supporting QUIC, TCP and HTTP transport protocols, capable of processing millions of messages per second.
- **uu\_mkdir**: mkdir ~ (uutils) create DIRECTORY
- **uu\_mv**: mv ~ (uutils) move (rename) SOURCE to DESTINATION
- **tokei**: Count your code, quickly.
- **boa\_gc**: Garbage collector for the Boa JavaScript engine.
- **cargo-llvm-cov**: Cargo subcommand to easily use LLVM source-based code coverage (-C instrument-coverage). 
- **uu\_touch**: touch ~ (uutils) change FILE timestamps
- **just**: 🤖 Just a command runner
- **sqlx-cli**: Command-line utility for SQLx, the Rust SQL toolkit.
- **tree-sitter-config**: User configuration of tree-sitter's command line programs
- **uu\_mktemp**: mktemp ~ (uutils) create and display a temporary file or directory from TEMPLATE
- **uu\_whoami**: whoami ~ (uutils) display user name of current effective user ID
