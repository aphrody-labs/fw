## About each crate

- **zeroize**: Securely clear secrets from memory with a simple trait built on stable Rust primitives which guarantee memory is zeroed using an operation will not be 'optimized away' by the compiler. Uses a portable pure Rust implementation that works everywhere, even WASM, with \`asm!\` optimizations on select platforms 
- **bumpalo**: A fast bump allocation arena for Rust.
- **arc-swap**: Atomically swappable Arc
- **once\_cell**: Single assignment cells and lazy values.
- **zerovec**: Zero-copy vector backed by a byte array
- **yoke**: Abstraction allowing borrowed data to be carried along with the backing data it borrows from
- **lazy\_static**: A macro for declaring lazily evaluated statics in Rust.
- **crossbeam-epoch**: Epoch-based garbage collection
- **crossbeam**: Tools for concurrent programming
- **compact\_str**: A memory efficient string type that transparently stores strings on the stack, when possible
- **get-size2**: Determine the size in bytes an object occupies inside RAM.
- **zerovec-derive**: Custom derive for the zerovec crate
- **slab**: Pre-allocated storage for a uniform data type
- **yoke-derive**: Custom derive for the yoke crate
- **mimalloc**: Performance and security oriented drop-in allocator
- **region**: Cross-platform virtual memory API
- **sdd**: Scalable lock-free delayed memory reclaimer
- **cudarc**: Safe and minimal CUDA bindings
- **slotmap**: Slotmap data structure
- **zeroize\_derive**: Custom derive support for zeroize
- **talc**: A fast and flexible allocator for no\_std and WebAssembly
- **flatbuffers**: Official FlatBuffers Rust runtime library.
- **zerofrom-derive**: Custom derive for the zerofrom crate
- **tor-memquota**: Memory use tracking and quota utilities, used by Tor software
- **zcheapstr**: An immutable, cheaply cloneable string type with borrowed, static and shared variants
