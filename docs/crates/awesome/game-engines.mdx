## About each crate

- **glam**: A simple and fast 3D math library for games and graphics
- **bevy**: A refreshingly simple data-driven game engine and app framework
- **bevy\_ecs**: Bevy Engine's entity component system
- **sdl2**: SDL2 bindings for Rust
- **gilrs**: Game Input Library for Rust
- **hecs**: A fast, minimal, and ergonomic entity-component-system library
- **bevy\_internal**: An internal Bevy crate used to facilitate optional dynamic linking via the 'dynamic\_linking' feature
- **godot**: Rust bindings for Godot 4
- **include\_dir**: Embed the contents of a directory in your binary
- **sdl3**: Bindings to SDL3, a cross-platform library to abstract the platform-specific details for building applications.
- **sdl2-sys**: Raw SDL2 bindings for Rust, used internally rust-sdl2
- **raylib**: Safe Rust bindings for Raylib.
- **transform-gizmo-egui**: egui integration for transform-gizmo
- **re\_math**: 3D math primitives built on top of glam: bounding boxes, rigid transforms, planes, rays and mesh generation.
- **bevy\_rand**: A plugin to integrate rand for ECS optimised RNG for the Bevy game engine.
- **godot-bindings**: Internal crate used by godot-rust
- **transform-gizmo**: 3D transformation gizmo
- **gilrs-core**: Minimal event-based abstraction for working with gamepads
- **bevy\_prng**: A crate providing newtyped RNGs for integration into Bevy.
- **mech-core**: The Mech language runtime.
- **godot-codegen**: Internal crate used by godot-rust
- **bevy\_prototype\_lyon**: Draw 2D shapes and paths in the Bevy game engine.
- **vpin**: Rust library for working with Visual Pinball VPX files
- **godot-core**: Internal crate used by godot-rust
- **godot-macros**: Internal crate used by godot-rust
