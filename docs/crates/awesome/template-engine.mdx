## About each crate

- **minijinja**: a powerful template engine for Rust with minimal dependencies
- **askama**: Type-safe, compiled Jinja-like templates for Rust
- **handlebars**: Handlebars templating implemented in Rust.
- **termimad**: Markdown Renderer for the Terminal
- **tera**: A template engine for Rust based on Jinja2/Django
- **askama\_parser**: Parser for Askama templates
- **fluent-templates**: Templating for the Fluent localization framework
- **typst-as-lib**: Small wrapper for typst that makes it easier to use it as a templating engine
- **askama\_web**: A compatibility add-on for Askama to support many different web frameworks
- **genco**: A whitespace-aware quasiquoter for beautiful code generation.
- **jq**: jq.rs transforms JSON using the jq language
- **sailfish**: Simple, small, and extremely fast template engine for Rust
- **template-quote**: A new-fashioned quote! macro implementation with pretty template-engine-like syntax
- **microsoft-webui-handler**: Core rust handler for WebUI framework
- **templated\_uri**: Standards-compliant URI handling with templating, validation, and data classification
- **upon**: A simple, powerful template engine with minimal dependencies and configurable delimiters
- **hayagriva**: Work with references: Literature database management, storage, and citation formatting
- **openjd-expr**: Open Job Description expression language — types, evaluation, and path mapping
- **sc-composer**: Standalone template composition library.
- **microsoft-webui**: Programmatic API for the WebUI build-time rendering framework
- **formatx**: A macro for formatting non literal strings at runtime
- **microsoft-webui-parser**: Core parser for WebUI framework
- **tera-contrib**: Additional filters, functions and tests for the Tera template engine
- **teravars**: Tera templating + smart \[vars\] handling for self-rendering TOML configs
- **templated\_uri\_macros**: Macros for the templated\_uri crate.
