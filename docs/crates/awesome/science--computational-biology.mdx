## About each crate

- **ann-search-rs**: Various vector search algorithms in Rust. Designed specifically for single cell & computational biology applications.
- **bixverse-sc-data**: The bixverse single cell data layer: binary sparse format, streaming readers and h5ad, 10x h5 and MTX ingestion.
- **bixverse-core**: Core numerics for bixverse: sparse structures, linear algebra, statistics, SIMD and clustering.
- **bixverse-sparse**: Compressed sparse structures for bixverse: CSR/CSC storage, transposition and sparse arithmetic, with no dense linear algebra dependency.
- **bixverse-rs**: A Rust library with various utilities for computational biology and single cell. Facade over the bixverse-\* crates.
- **bixverse-methods**: Bulk omics methods for bixverse: enrichment, graphs, ontologies, matrix factorisation and differential expression.
- **bonsai-rs**: Tree representations of high-dimensional data under Brownian motion. A clean-room Rust implementation of the Bonsai algorithm for single cell and computational biology applications.
- **bixverse-sc**: Single cell and metacell analysis for bixverse: processing, batch correction, annotation, trajectories and differential expression.
- **sanity-sc-rs**: Bayesian inference of gene expression states from single cell UMI counts. A clean-room Rust implementation of the Sanity method, returning posterior log expression levels and their error bars.
- **bixverse-r**: R bindings layer for bixverse: extendr conversions for the bixverse-\* crates. Re-exports bixverse-rs.
