## About each crate

- **syn**: Parser for Rust source code
- **quote**: Quasi-quoting macro quote!(...)
- **proc-macro2**: A substitute implementation of the compiler's \`proc\_macro\` API to decouple token-based libraries from the procedural macro use case.
- **inventory**: Typed distributed plugin registration
- **unicode-ident**: Determine whether characters have the XID\_Start or XID\_Continue properties according to Unicode Standard Annex #31
- **clap\_derive**: Parse command line argument by defining a struct, derive crate.
- **ctor**: Global, no\_std-compatible constructors for all platforms that run before main (like C/C++ \_\_attribute\_\_((constructor)))
- **strum**: Helpful macros for working with enums and strings
- **linkme**: Safe cross-platform linker shenanigans
- **derive\_more**: Adds #\[derive(x)\] macros for more traits
- **strum\_macros**: Helpful macros for working with enums and strings
- **proc-macro-crate**: Replacement for crate (macro\_rules keyword) in proc-macros 
- **litrs**: Parse and inspect Rust literals (i.e. tokens in the Rust programming language representing fixed values). Particularly useful for proc macros, but can also be used outside of a proc-macro context. 
- **dtor**: Global, no\_std-compatible destructors for all platforms that run after main (like C/C++ \_\_attribute\_\_((destructor)))
- **zenoh-macros**: Internal crate for zenoh.
- **proc-macro-error3**: Almost drop-in replacement to panics in proc-macros
- **manyhow**: proc macro error handling à la anyhow x proc-macro-error
- **link-section**: Link-time initialized slices for Rust, with full support for Linux, macOS, Windows, WASM and many more platforms.
- **unicode-id-start**: Determine whether characters have the ID\_Start or ID\_Continue properties according to Unicode Standard Annex #31
- **serde\_tokenstream**: A serde deserializer for proc\_macro::TokenStreams
- **verus\_syn**: Parser for Rust source code extended to support Verus
- **getset**: Getset, we're ready to go!  A procedural macro for generating the most basic getters and setters on fields. 
- **structmeta**: Parse Rust's attribute arguments by defining a struct.
- **contracts**: Design-by-contract attributes
- **macro-string**: Eager evaluation of macros like \`concat!\` and \`env!\`
