## About each crate

- **regex**: An implementation of regular expressions for Rust. This implementation uses finite automata and guarantees linear time matching on all inputs. 
- **pulldown-cmark**: A pull parser for CommonMark
- **fancy-regex**: An implementation of regexes, supporting a relatively rich set of features, including backreferences and look-around. Aims to be compatible with Oniguruma syntax when the relevant flag is set.
- **encoding\_rs**: A Gecko-oriented implementation of the Encoding Standard
- **unicode-width**: Determine displayed width of \`char\` and \`str\` types according to Unicode Standard Annex #11 rules. 
- **bstr**: A string type that is not required to be valid UTF-8.
- **regex-automata**: Automata construction and matching using regular expressions.
- **skrifa**: Metadata reader and glyph scaler for OpenType fonts.
- **calamine**: An Excel/OpenDocument Spreadsheet reader and deserializer in pure Rust
- **comrak**: A 100% CommonMark-compatible GitHub Flavored Markdown parser and formatter
- **lopdf**: A Rust library for PDF document manipulation.
- **read-fonts**: Reading OpenType font files.
- **chumsky**: A parser library for humans with powerful error recovery
- **harfrust**: A complete HarfBuzz shaping algorithm port to Rust.
- **scraper**: HTML parsing and querying with CSS selectors
- **ammonia**: HTML Sanitization
- **textwrap**: Library for word wrapping, indenting, and dedenting strings. Has optional support for Unicode and emojis as well as machine hyphenation.
- **const\_format**: Compile-time string formatting
- **compact\_str**: A memory efficient string type that transparently stores strings on the stack, when possible
- **aho-corasick**: Fast multiple substring searching.
- **indoc**: Indented document literals
- **lazy-regex**: lazy static regular expressions checked at compile time
- **write-fonts**: Writing font files.
- **convert\_case**: Convert strings into any case
- **two-face**: Extra syntax and theme definitions for syntect
