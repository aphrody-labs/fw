## About each crate

- **thiserror**: derive(Error)
- **anyhow**: Flexible concrete Error type built on std::error::Error
- **ordered-float**: Wrappers for total ordering on floats
- **zerocopy**: Zerocopy makes zero-cost memory manipulation effortless. We write "unsafe" so you don't have to.
- **pin-project**: A crate for safe and ergonomic pin-projection. 
- **bumpalo**: A fast bump allocation arena for Rust.
- **itertools**: Extra iterator adaptors, iterator methods, free functions, and macros.
- **pin-project-lite**: A lightweight version of pin-project written with declarative macros. 
- **bon**: Next-gen compile-time-checked builder generator, named function's arguments, and more!
- **once\_cell**: Single assignment cells and lazy values.
- **zerovec**: Zero-copy vector backed by a byte array
- **lazy\_static**: A macro for declaring lazily evaluated statics in Rust.
- **educe**: This crate offers procedural macros designed to facilitate the swift implementation of Rust's built-in traits.
- **erased-serde**: Type-erased Serialize and Serializer traits
- **snafu**: An ergonomic error handling library
- **indoc**: Indented document literals
- **derive\_more**: Adds #\[derive(x)\] macros for more traits
- **eyre**: Flexible concrete Error Reporting type built on std::error::Error with customizable Reports
- **bitvec**: Addresses memory by bits, for packed collections and bitfields
- **derive-where**: Deriving with custom trait bounds
- **rgb**: \`struct RGB/RGBA/etc.\` for sharing pixels between crates + convenience methods for color manipulation. Allows no-copy high-level interoperability. Also adds common convenience methods and implements standard Rust traits to make \`RGB\`/\`RGBA\` pixels and slices first-class Rust objects.
- **ref-cast**: Safely cast &T to &U where the struct U contains a single field of type T.
- **zerovec-derive**: Custom derive for the zerovec crate
- **cargo\_toml**: \`Cargo.toml\` struct definitions for parsing with Serde
- **imgref**: A basic 2-dimensional slice for safe and convenient handling of pixel buffers with width, height & stride
