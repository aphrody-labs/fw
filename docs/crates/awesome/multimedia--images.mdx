## About each crate

- **usvg**: An SVG simplification library.
- **image**: Imaging library. Provides basic image processing and encoders/decoders for common image formats.
- **zune-jpeg**: A fast, correct and safe jpeg decoder
- **moxcms**: Simple Color Management in Rust
- **png**: PNG decoding and encoding library in pure Rust
- **qrcode**: QR code encoder in Rust
- **rgb**: \`struct RGB/RGBA/etc.\` for sharing pixels between crates + convenience methods for color manipulation. Allows no-copy high-level interoperability. Also adds common convenience methods and implements standard Rust traits to make \`RGB\`/\`RGBA\` pixels and slices first-class Rust objects.
- **tiff**: TIFF decoding and encoding library in pure Rust
- **yuv**: High performance utilities for YUV format handling and conversion.
- **skia-safe**: Safe Skia Bindings for Rust
- **imgref**: A basic 2-dimensional slice for safe and convenient handling of pixel buffers with width, height & stride
- **pdfium-render**: A high-level idiomatic Rust wrapper around Pdfium, the C++ PDF library used by the Google Chromium project.
- **palette**: Convert and manage colors with a focus on correctness, flexibility and ease of use.
- **zune-core**: Core utilities for image processing in the zune family of crates
- **kamadak-exif**: Exif parsing library written in pure Rust
- **color\_quant**: Color quantization library to reduce n colors to 256 colors.
- **pic-scale**: High performance image scaling
- **qrcode-generator**: Generates ISO/IEC 18004 QR Code and Micro QR Code symbols and ISO/IEC 23941 rMQR symbols in pure Rust, then renders them as grayscale, PNG and SVG images.
- **jpeg-encoder**: JPEG encoder
- **skia-bindings**: Skia Bindings for Rust
- **img-parts**: Low level crate for reading and writing Jpeg, Png and RIFF image containers
- **jxl**: High performance Rust implementation of a JPEG XL decoder
- **dicom-pixeldata**: A high-level API for decoding DICOM objects into images and ndarrays
- **gamut-core**: Core traits, image buffers, dimensions, and error types shared across the gamut image codecs.
- **icy\_sixel**: A 100% Rust SIXEL encoder and decoder library with high-quality color quantization
