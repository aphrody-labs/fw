## About each crate

- **ankaios\_sdk**: Eclipse Ankaios Rust SDK - provides a convenient Rust interface for interacting with the Ankaios platform.
- **dbc-codegen**: CAN DBC code-gen for embedded Rust
- **visa-rs**: Safe rust bindings for VISA(Virtual Instrument Software Architecture) library
- **ace-core**: Foundation layer for ACE: codec traits (FrameRead, FrameWrite, Writer), bounded storage, and the time, addressing, transport, randomness, and diagnostic-node abstractions every other ace-\* crate builds on. no\_std, no allocator required.
- **host-can**: Host library for CAN adapters
- **ace-proto**: Raw frame wrappers with no protocol knowledge. Provides UDS, DoIP, and CAN Frames with mutable variants.
- **ace-macros**: Proc-macro crate. Provides FrameCodec which generates FrameRead and FrameWrite impls for structs and enums.
- **ace-uds**: UDS typed message layer implementing ISO 14229-1.
- **ace-doip**: DoIP typed message and session layer implementing ISO 13400-2.
- **ace-client**: UDS tester client state machine.
- **can\_decode**: Decode and encode CAN frames into messages/signals in a fast and easy way.
- **dbc-codegen2**: DBC code generator for CAN bus messages
- **kuksa-rust-sdk**: The Rust SDK for the Eclipse KUKSA Databroker.
