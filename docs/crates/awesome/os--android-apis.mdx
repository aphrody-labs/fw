## About each crate

- **i-slint-backend-android-activity**: Android backend for Slint
- **apk-info-axml**: Library for working with AXML and ARSC in APK files
- **apk-info**: Fast, malware-robust parser for Android apk/xapk/apkm/apks files
- **android\_logger**: A logging implementation for \`log\` which hooks to android log output. 
- **android-usb-serial**: Pure Rust USB serial drivers for Android (and Linux), built on nusb
- **liveupdate**: Android Live Updates from Rust
- **jvm-getter**: JNI\_GetCreatedJavaVMs for Android API 30 or lower
- **robius-android-env**: Rust access to Android state (native Java objects) managed by UI toolkits
