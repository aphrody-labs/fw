## About each crate

- **skia-safe**: Safe Skia Bindings for Rust
- **skia-bindings**: Skia Bindings for Rust
- **vk-parse**: Vulkan specification parser
- **miniquad**: Cross-platform window context and rendering library. 
- **tracel-ash**: Vulkan bindings for Rust
- **gpu-allocator**: Memory allocator for GPU memory in Vulkan and DirectX 12
- **ash**: Vulkan bindings for Rust
- **vulkano**: Safe wrapper for the Vulkan graphics API
- **martensite-core**: Generational slotmap arena, widget traits, and node graph for Martensite.
- **freya-skia-safe**: Safe Skia Bindings for Rust
- **freya-skia-bindings**: Skia Bindings for Rust
- **emblema-hal**: Rendering hardware abstraction layer for emblema.
- **martensite-reactive**: Fine-grained push-pull reactive signal DAG for Martensite.
- **piet**: An abstraction for 2D graphics.
- **wgpu-external-frame**: Zero-copy import of externally produced GPU frames into wgpu textures: Linux DMA-BUF, Android AHardwareBuffer, macOS and iOS IOSurface, and Windows shared handles
- **imgui-wgpu**: A wgpu render backend for imgui-rs.
- **jay-ash**: Vulkan bindings for Rust
- **martensite-theme**: Semantic design tokens, Oklab perceptual uniform GPU blending, and 150ms spring transitions.
- **emblema-shaders**: WGSL shader sources for emblema, translated at build time by naga.
- **raui-core**: RAUI application layer
- **martensite-render**: Hardware-agnostic PaintList command stream and TinySkia CPU fallback backend.
- **emblema-hal-vulkan**: Vulkan rendering backend for emblema.
- **spirv-cross-sys**: Raw bindings to SPIRV-Cross
- **pyronyx**: Better Vulkan bindings for Rust
- **ash-window**: Interop library between ash and raw-window-handle
