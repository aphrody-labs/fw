## About each crate

- **portable-atomic**: Portable atomic types including support for 128-bit atomics, atomic float, etc. 
- **cortex-m**: Low level access to Cortex-M processors
- **wide**: A crate to help you go wide.
- **fearless\_simd**: Safer and easier SIMD
- **r-efi**: UEFI Reference Specification Protocol Constants and Definitions
- **cpufeatures**: Lightweight runtime CPU feature detection for aarch64, loongarch64, and x86/x86\_64 targets, with no\_std support and support for mobile targets including Android and iOS 
- **multiversion**: Easy function multiversioning
- **nvml-wrapper**: A safe and ergonomic Rust wrapper for the NVIDIA Management Library
- **nusb**: Cross-platform low-level access to USB devices in pure Rust
- **serial2**: Cross platform serial ports
- **cryptoki**: Rust-native wrapper around the PKCS #11 API
- **serialport**: A cross-platform low-level serial port library.
- **esp-hal**: Bare-metal HAL for Espressif devices
- **cudarc**: Safe and minimal CUDA bindings
- **riscv**: Low level access to RISC-V processors
- **uart\_16550**: Simple yet highly configurable low-level driver for 16550 UART devices, typically known and used as serial ports or COM ports. Easy integration into Rust while providing fine-grained control where needed (e.g., for kernel drivers). 
- **iced-x86**: iced-x86 is a blazing fast and correct x86/x64 disassembler, assembler and instruction decoder written in Rust
- **embedded-storage**: A Storage Abstraction Layer for Embedded Systems
- **sev**: Library for AMD SEV
- **bt-hci**: Bluetooth HCI data types
- **cmov**: Conditional move CPU intrinsics which are guaranteed on major platforms (ARM32/ARM64, x86/x86\_64, RISC-V) to execute in constant-time and not be rewritten as branches by the compiler. Provides wrappers for the CMOV family of instructions on x86/x86\_64 and CSEL on AArch64, along with a portable "best-effort" pure Rust fallback implementation. 
- **crc-fast**: World's fastest generic CRC16, CRC32, and CRC64 calculator using SIMD. Supplies a C-compatible shared library for use in other languages.
- **safe\_arch**: Crate that exposes \`core::arch\` safely via \`#\[cfg()\]\`.
- **archmage**: Safely invoke your intrinsic power, using the tokens granted to you by the CPU. Cast primitive magics faster than any mage alive.
- **esp-idf-hal**: A Hardware abstraction layer for Espressif's ESP family of microcontrollers based on the ESP-IDF framework.
