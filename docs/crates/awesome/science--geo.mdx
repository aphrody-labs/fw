## About each crate

- **rstar**: An R\*-tree spatial index
- **i\_overlay**: Boolean Operations for 2D Polygons: Supports intersection, union, difference, xor, and self-intersections for all polygon varieties.
- **geo**: Geospatial primitives and algorithms
- **pmtiles**: Implementation of the PMTiles v3 spec with multiple sync and async backends.
- **geoarrow-schema**: GeoArrow geometry type and metadata definitions.
- **geoarrow-array**: GeoArrow array definitions.
- **wkb**: Fast, pure-Rust reader and writer for Well-Known Binary geometries
- **tzf-rs**: Fast convert longitude,latitude to timezone name.
- **proj**: High-level Rust bindings for the latest stable version of PROJ
- **geodatafusion**: Spatial extensions for Apache DataFusion
- **geo-index**: Fast, immutable, ABI-stable spatial indexes.
- **martin-tile-utils**: Utilities to help with map tile processing, such as type and compression detection. Used by the MapLibre's Martin tile server.
- **mlt-core**: MapLibre Tile library code
- **tilejson**: Library for serializing the TileJSON file format
- **h3o**: A Rust implementation of the H3 geospatial indexing system.
- **geoarrow**: GeoArrow amalgamation crate.
- **mbtiles**: A simple low-level Mbtiles access and processing library, with some tile format detection and other relevant heuristics.
- **walkers**: slippy map widget for egui
- **proj4rs**: Rust adaptation of Proj4
- **fast-mvt**: Fast Mapbox Vector Tile (MVT) reader and writer
- **geoarrow-expr-geo**: Rust implementation of GeoArrow
- **geozero**: Zero-Copy reading and writing of geospatial data in WKT/WKB, GeoJSON, MVT, GDAL, and other formats.
- **clipper2**: A safe, idiomatic Rust API for 2D polygon boolean clipping (intersection, union, difference, XOR), offsetting (inflate/deflate), Minkowski sum/difference, simplification, area, and point-in-polygon, on top of Clipper2.
- **geoparquet**: GeoParquet reader and writer.
- **icechunk**: Transactional storage engine for Zarr designed for use on cloud object storage
