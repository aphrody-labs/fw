## About each crate

- **clap**: A simple to use, efficient, and full-featured Command Line Argument Parser
- **clap\_complete**: Generate shell completion scripts for your clap::Command
- **ratatui**: A library that's all about cooking up terminal user interfaces
- **unicode-width**: Determine displayed width of \`char\` and \`str\` types according to Unicode Standard Annex #11 rules. 
- **indicatif**: A progress bar and cli reporting library for Rust
- **clap\_mangen**: A manpage generator for clap
- **clap\_derive**: Parse command line argument by defining a struct, derive crate.
- **inquire**: inquire is a library for building interactive prompts on terminals
- **clap\_lex**: Minimal, flexible command line parser
- **owo-colors**: Zero-allocation terminal colors that'll make people go owo
- **shlex**: Split a string into shell words, like Python's shlex.
- **textwrap**: Library for word wrapping, indenting, and dedenting strings. Has optional support for Unicode and emojis as well as machine hyphenation.
- **clap\_complete\_nushell**: A generator library used with clap for Nushell completion scripts
- **clap\_builder**: A simple to use, efficient, and full-featured Command Line Argument Parser
- **ratatui-core**:     Core types and traits for the Ratatui Terminal UI library.     Widget libraries should use this crate. Applications should use the main Ratatui crate. 
- **vt100**: Library for parsing terminal data
- **rustyline**: Rustyline, a readline implementation based on Antirez's Linenoise
- **anstyle**: ANSI text styling
- **fs-err**: A drop-in replacement for std::fs with more helpful error messages.
- **termimad**: Markdown Renderer for the Terminal
- **bpaf**: A simple Command Line Argument Parser with parser combinators
- **ratatui-widgets**: A collection of Ratatui widgets for building terminal user interfaces using Ratatui.
- **human-panic**: Panic messages for humans
- **anstream**: IO stream adapters for writing colored text that will gracefully degrade according to your terminal's capabilities.
- **ratatui-crossterm**: Crossterm backend for the Ratatui Terminal UI library.
