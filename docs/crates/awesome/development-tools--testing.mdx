## About each crate

- **proptest**: Hypothesis-like property-based testing and shrinking. 
- **arbitrary**: The trait for generating structured data from unstructured data
- **insta**: A snapshot testing library for Rust
- **testcontainers**: A library for integration-testing against docker containers from within Rust.
- **serial\_test**: Allows for the creation of serialised Rust tests
- **trybuild**: Test harness for ui tests of compiler diagnostics
- **assert\_cmd**: Test CLI Applications.
- **rstest**: Rust fixture based test framework. It use procedural macro to implement fixtures and table based tests. 
- **proptest-derive**: Custom-derive for the Arbitrary trait of proptest. 
- **mockall**: A powerful mock object library for Rust. 
- **tokio-test**: Testing utilities for Tokio- and futures-based code 
- **skeptic**: Test your Rust markdown documentation via Cargo
- **thirtyfour**: Thirtyfour is a Selenium / WebDriver library for Rust, for automated website UI testing.  Tested on Chrome and Firefox, but any webdriver-capable browser should work. 
- **test-case**: Provides #\[test\_case(...)\] procedural macro attribute for generating parametrized test cases easily
- **shuttle**: A library for testing concurrent Rust code
- **codspeed**: Core instrumentation library for CodSpeed
- **assert2**: assert!(...) and check!(...) macros inspired by Catch2, now with diffs!
- **egui\_kittest**: Testing library for egui based on kittest and AccessKit
- **axum-test**: Easy E2E testing for Axum
- **test-log**: A replacement of the #\[test\] attribute that initializes logging and/or tracing infrastructure before running tests. 
- **antithesis\_sdk**: Rust SDK for the Antithesis autonomous software testing platform. 
- **crabgrind**: Rust bindings to "Valgrind Client Request" interface
- **httpmock**: HTTP mocking library for Rust
- **chromiumoxide**: Library for interacting with a chrome instance with the chrome devtools protocol
- **derive\_arbitrary**: Derives arbitrary traits
