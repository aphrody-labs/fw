## About each crate

- **tracing**: Application-level tracing for Rust. 
- **opentelemetry**: OpenTelemetry API for Rust
- **opentelemetry-otlp**: Exporter for the OpenTelemetry Collector
- **tracing-subscriber**: Utilities for implementing and composing \`tracing\` subscribers. 
- **tracing-opentelemetry**: OpenTelemetry integration for tracing
- **opentelemetry-semantic-conventions**: Semantic conventions for OpenTelemetry
- **opentelemetry-proto**: Protobuf generated files and transformations.
- **criterion**: Statistics-driven micro-benchmarking library
- **gimli**: A library for reading and writing the DWARF debugging format.
- **opentelemetry-prometheus**: Prometheus exporter for OpenTelemetry
- **tracing-core**: Core primitives for application-level tracing. 
- **opentelemetry-stdout**: An OpenTelemetry exporter for stdout
- **hdrhistogram**: A port of HdrHistogram to Rust
- **codspeed**: Core instrumentation library for CodSpeed
- **profiling**: This crate provides a very thin abstraction over other profiler crates.
- **axum-tracing-opentelemetry**: Middlewares and tools to integrate axum + tracing + opentelemetry
- **inferno**: Rust port of the FlameGraph performance profiling tool suite
- **crabgrind**: Rust bindings to "Valgrind Client Request" interface
- **codspeed-criterion-compat**: Criterion.rs compatibility layer for CodSpeed
- **gloo-console**: Convenience crate for working with browser's console
- **tpchgen**: Blazing fast pure Rust zero dependency TPC-H data generation library.
- **opentelemetry-datadog**: \[DEPRECATED\] Datadog exporters and propagators for OpenTelemetry. Use https://github.com/DataDog/dd-trace-rs instead.
- **tracing-attributes**: Procedural macro attributes for automatically instrumenting functions. 
- **opentelemetry-aws**: AWS exporters and propagators for OpenTelemetry
- **gungraun**: High-precision, one-shot and consistent benchmarking framework for Rust. All Valgrind tools and Linux perf at your fingertips.
