## About each crate

- **slint**: Declarative GUI toolkit to build native user interfaces for desktop, Android, iOS, the web, and embedded devices, from microcontrollers to embedded Linux
- **slint-build**: Compile .slint UI files to Rust code from a Cargo build script
- **meshopt**: Rust ffi bindings and idiomatic wrapper for mesh optimizer
- **block\_compression**: Texture block compression using WGPU compute shader
- **valo**: A 2D render engine on wgpu: display lists, planned GPU passes, and a Skia-shaped text stack
- **valo-geometry**: Pure 2D math for valo: points, rects, paths, 4x4 matrices, strokes, color
- **slint-interpreter**: Load .slint UI files at run time, without compiling them ahead of time
- **valo-text**: Fonts, shaping and glyph raster for valo: font collections and fallback, harfrust shaping, glyph masks, SDF, COLR
- **valo-dl**: Display-list recording for valo, with the record-time oracle the renderer replays
- **valo-codec**: Image decoding for Valo: a decoder interface, ordered fallback, and inline or worker-thread execution
- **valo-system-fonts**: The platform's installed fonts as valo's FontSource, over a valo-fontmgr font manager
- **valo-fontmgr**: Installed fonts, found the way Skia's SkFontMgr finds them: by family and style, by the character to cover, and the platform's own UI font
- **valo-codec-software**: Portable image codecs for Valo: PNG, JPEG, GIF, WebP and BMP decoded on the CPU
- **hephaestus**: Backend-agnostic 2D scene renderer for data visualization.
- **nightshade**: A cross-platform data-oriented game engine.
- **valo-renderer**: The wgpu core of valo: frame planner, encoder, pipelines, glyph atlases, caches
- **valo-paragraph**: Styled paragraphs for valo: spans, font fallback, bidi, wrapping, and recording into a display list
- **emblema**: A Flutter-class 2D renderer: Vulkan and GLES backends, WSI and DRM/KMS presentation.
- **intel\_tex\_2**: Rust bindings for Intel's ISPC texture compressor.
- **egui-charts**: High-performance financial charting engine for egui — candlesticks, 95 drawing tools, 130+ indicators, and a full design-token theme system
- **textcanvas**: Draw to the terminal like an HTML Canvas.
- **vk-mem**: Rust ffi bindings and idiomatic wrapper for AMD Vulkan Memory Allocator (VMA)
- **spirv-reflect**: Reflection API in rust for SPIR-V shader byte code, intended for Vulkan applications.
- **vk-sync-fork**: Simplification of core Vulkan synchronization mechanisms such as pipeline barriers and events. Forked off of the original vk-sync crate which is currently unmaintained.
- **rafx-base**: Rendering framework built on an extensible asset pipeline
