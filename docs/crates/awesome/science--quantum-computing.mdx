## About each crate

- **hugr-core**: Quantinuum's Hierarchical Unified Graph Representation
- **hugr**: Quantinuum's Hierarchical Unified Graph Representation
- **hugr-model**: Data model for Quantinuum's HUGR intermediate representation
- **hugr-cli**: Compiler passes for Quantinuum's HUGR
- **hugr-llvm**: A general and extensible crate for lowering HUGRs into LLVM IR
- **tket**: Quantinuum's TKET Quantum Compiler
- **tket-qsystem**: TKET tool for preparing and validating \`Hugr\`s for compilation targeting Quantinuum H-series  quantum computers
- **tk-pg-core**: Core types and pass interfaces for Pauli graphs
- **tk-pg-ir-kernels**: Rewrite operations and tableau interfaces for Pauli graphs
- **tk-pg-utils**: Shared utilities for the pg-libs crates
- **tk-pg-qm-tableau**: Clifford tableaux with a qubit major memory layout
- **tk-pg-canonical-form**: Canonical form transformations for Pauli graphs
- **tk-pg-bitpacked**: Clifford conjugation kernels for packed Pauli representations
- **tk-pg-optimize**: Optimization passes for Pauli graphs
- **tk-pg-greedy-synth**: Greedy synthesis passes for Pauli graphs
- **tk-pg-rebase**: Rebasing passes for Pauli graphs
- **qir-qis**: QIR to Quantinuum QIS (Quantum Instruction Set) compiler
- **tk-pg-t-optimize**: T-count optimization passes for Pauli graphs
- **qir-formatter**: Rust implementation of the QIR labeled results formatter
