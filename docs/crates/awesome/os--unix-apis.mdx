## About each crate

- **nix**: Rust friendly bindings to \*nix APIs
- **rustix**: Safe Rust bindings to POSIX/Unix/Linux/Winsock-like syscalls
- **zbus**: API for D-Bus communication and its wire format
- **interprocess**: Interprocess communication toolkit
- **fuser**: Filesystem in Userspace (FUSE) for Rust
- **blazesym**: blazesym is a library for address symbolization and related tasks.
- **dbus**: Bindings to D-Bus, which is a bus commonly used on Linux for inter-process communication.
- **zbus\_names**: A collection of D-Bus bus names types (deprecated: merged into zbus)
- **fork**: Library for creating a new process detached from the controlling terminal (daemon)
- **alsa-sys**: FFI bindings for the ALSA project (Advanced Linux Sound Architecture)
- **zbus\_polkit**: PolicyKit binding
- **rlimit**: Resource limits
- **kqueue-sys**: Low-level kqueue interface for BSDs
- **procfs**: Interface to the linux procfs pseudo-filesystem
- **rexpect**: Interact with unix processes/bash the same way as pexpect or Don libes expect does
- **blazesym-c**: C bindings for blazesym
- **memfd**: A pure-Rust library to work with Linux memfd and sealing
- **kqueue**: kqueue interface for BSDs
- **nftnl**: Safe abstraction for libnftnl. Provides low-level userspace access to the in-kernel nf\_tables subsystem
- **freedesktop-desktop-entry**: Freedesktop Desktop Entry Specification
- **cgroups-rs**: Native Rust crate for managing control groups on Linux
- **waitpid-any**: Wait for any PID, an extension to waitpid(2)
- **processkit**: Async child-process management for tokio: whole-tree kill-on-drop (no orphans), plus streaming, pipelines, timeouts, and supervision
- **sys-mount**: High level FFI binding around the sys mount & umount2 calls
- **unix-ancillary**: Safe, ergonomic Unix socket ancillary data (SCM\_RIGHTS fd passing) with OwnedFd/BorrowedFd
